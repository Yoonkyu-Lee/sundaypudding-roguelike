## 3. 상태이상 & 특수효과

### 3.1 통일 모델 — "타임드 인스턴스 원장(ledger)"

| 항목 | 결정 | 상태 |
|---|---|---|
| 기본 방식 | **스택형(B)**: 세기는 스택, 시간은 별도 지속턴 (둘을 분리) | ✓ |
| 저장 구조 | 상태이상 = **타임드 인스턴스의 목록**. 적용 1건 = `{출처, +스택, 잔여턴}` 1개 인스턴스 | ✓ |
| 합산 | **현재 총 스택 = 인스턴스들의 합.** 인스턴스는 합치지 않고 각자 독립 만료 | ✓ |
| 효과는 사실 | "3→1로 줄어듦"이 계산이 아니라 **데이터에 박힌 사실**로 표현됨 (출처/만료 자동 보존) | ✓ |

```
예) 화상 = [
  { 출처: 아군A 화염스킬,  +2스택, 잔여 3턴 },
  { 출처: 함정,           +1스택, 잔여 1턴 },
]   → 현재 총 스택 3, 다음 턴 함정분 만료되어 1로 감소
```

### 3.2 표시 — 점진적 공개(progressive disclosure)

**글랜스(아이콘, 한눈):**
| 위치 | 표시 | 뜻 |
|---|---|---|
| 아이콘 | 🔥 | 상태 종류 (색·모양으로 즉시 구분) |
| superscript | ³ | **현재 총 스택**(세기) |
| subscript | ₅ | **완전 소멸까지 남은 턴**(가장 늦은 인스턴스) |
| `▾` 마커 | 🔥³˙⁵▾ | **다음 변화까지 턴**(가장 빠른 만료) — "곧 약해진다" |
| 아이콘 ↑/↓ | — | 이번 턴 스택 **추세**(증가/감소) — 호버 없이 모멘텀 인지 |

**호버(상세 창):** 원장을 그대로 표시 — **각 인스턴스의 출처·스택·잔여턴**. (누가 건 효과인지 보임)

### 3.3 북극성 사수 라인 ⚠️

> **기본 플레이는 글랜스(³/₅/▾/추세)만으로 충분해야 한다.**
> **호버는 최적화·민맥싱용 보너스 정보다. 호버를 안 보면 못 깨는 게임이 되면 북극성 위반.**

이 모델은 깊이를 위해 직관성을 *의도적으로 조금* 양보한 결정이며, 위 라인이 그 양보의 한계선이다.

### 3.4 두 갈래: 전역 상태이상 vs 특수효과

- **전역(global) 상태이상**: 규칙·세기가 **표준화**되어 어디서나 동일. 세기가 고정이라 글랜스 표기가 거짓 없음.
- **특수효과(source-dependent)**: 세기/거동이 **출처에 따라 다름**. 그래서 버프/상태 목록에 표시하되 **펼치면 출처**가 보여야 함(3.1 원장 모델이 이걸 자동 처리).

### 3.5 전역 상태이상 목록 (표준화)

| 효과 | 거동 | 세기 | 발동 시점 |
|---|---|---|---|
| **화상** | 지속 피해 | 스택당 `x` | **턴 종료 시** |
| **중독** | 지속 피해 | 스택당 `x` | **턴 시작 시** |
| **출혈** | 지속 피해 | 스택당 `x` | **행동 시** (정규 턴 + 끼어들기 모두 — 2.11) |
| **마비** | SPD 하락 → **행동 서열 재배열로 밀림** | (밸런스) | 상시 |
| **동상** | **주는 데미지 50% 하락** | 고정 ×0.5 | 상시 (공격 시 적용) |
| **빙결** | 행동 서열에서 **비활성화 = 그 턴 행동불가** | — | 해당 턴 |
| **공포** | **쉴드 깎는 효율 악화**: 들어온 피해 1이 쉴드를 **(공포 스택)만큼** 깎음. (예: 6스택 → 피해1이 쉴드 6 깎음). **단 HP 깎는 효율은 불변** | 스택 배율 | 피격 시(쉴드에만) |

> `x`(화상·중독·출혈의 스택당 피해)는 임시 placeholder. 밸런스 조정으로 확정. ☐
> 공포: 스택 배율이므로 1스택=등배(실효 미미), 2스택+부터 의미. 밸런스 시 조정 가능. ☐

### 3.6 특수효과 목록 (출처 의존)

| 효과 | 거동 | 비고 |
|---|---|---|
| **관통** | (아군 부여) 적이 쉴드를 가져도 공격이 **쉴드 무시하고 온전히 HP를 깎음** | 쉴드 레이어 우회 |
| **재생** | 턴 종료 시 회복 | 회복량이 출처마다 달라 전역 아님 → 버프목록+출처 |
| **불사** | HP가 0이 되어도 **1턴 동안 죽지 않음** | 버티기 |
| **공위증** | **주는 데미지 합연산 +** (버프) | 정도가 출처마다 달라 전역 아님. 버프목록에 `공위증(데미지 합연산)` 표시, 펼치면 출처 |

### 3.7 데미지 보정 규칙 (전역 원칙)

| 규칙 | 결정 | 상태 |
|---|---|---|
| 가변 데미지 버프(공위증류)는 **합연산(flat)만**. **% / 곱연산 없음** | ✓ | ✓ |
| 곱연산은 **표준화된 전역 상태이상만** 사용 가능 (예: 동상 ×0.5). 가변/출처의존 효과는 합연산만 | ✓ | ✓ |
| **데미지 계산 순서**: `(스킬상수 + 합연산보정) × 전역배율(동상 등) × crit배수` → 결과는 `원본→현재` 병기 | ✓ | ✓ |

> 예: 스킬 20, 공위증 +10, 동상, 크리 → `(20+10) × 0.5 × 1.5 = 22`. 화면 표기 `20 → 22`.

### 3.8 ★ 도출된 일관성 — "방어는 오직 쉴드 레이어"

전역/특수 효과를 종합하면 다음 구조가 도출됨 (✓ 확정):
- **HP에 들어가는 피해 자체는 방어측이 감소/증폭하지 못함.** (받피감% 없음 — 이미 확정)
- **공격측**만 자기 출력을 보정: 동상(−), 공위증(+).
- **방어측**은 오직 **쉴드 레이어**만 조작: 쉴드량 / 공포(쉴드 잠식 가속) / 관통(쉴드 무시).
- → "버티는 건 보이는 쉴드로만, 무너뜨리는 건 공포·관통·DoT로." 매우 선명한 구조.

### 3.9 프리미티브(엔진용 역도출)

위 효과들을 엔진이 아는 원자 단위로 환원:
1. **시점부 지속피해** `{trigger: 턴시작|턴종료|행동시, amount: 스택×x}`
2. **시점부 지속회복** `{trigger: 턴종료, amount: 출처정의}`
3. **능력치 보정** (SPD↓ 등 → 서열 재계산 트리거 포함)
4. **주는 데미지 보정** (합연산 / 전역고정배율)
5. **행동 봉쇄** (서열에서 비활성)
6. **쉴드 부여** (상한 있는 덤 HP)
7. **쉴드 잠식 배율** (공포)
8. **쉴드 무시** (관통)
9. **사망 방지** (불사, 1턴)
10. **주는 데미지 합연산 보정** (투지/공위증+ · 약화−), **치명 보정**(예리·은신: critChanceAdd/critMultiplierAdd)
11. **무적**(모든 피해 0) · **도발**(적 공격 집중, AI 참조) · **마비**(speedDown→서열 밀림, 3.5)
12. **정화**(cleanse) · **시전자 자기효과**(applyStatusSelf, 광역 중복 방지)
13. **면적(AoE) 모양**: `area` = single/row/col/square(radius)/cross(radius)/all/**free(자유 인접 N칸)**. **앵커=선택 칸(빈 칸도 가능)** 기준으로 영향 칸 결정, 풋프린트 내 같은 진영 유닛에 적용. **타겟팅은 셀 기반**(유닛 없는 칸도 클릭), 웹은 **바닥에 영향 칸 하이라이트 + 자유선택 단계별 인접 칸 제시**(2.4 확장).
