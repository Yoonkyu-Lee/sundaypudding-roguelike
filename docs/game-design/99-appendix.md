## 부록 A. 확정 결정 로그 (요약)

**철학·원칙**
1. 육성형 로그라이크 (덱빌딩 제외)
2. 북극성: 다키스트의 반대 / 포켓몬급 직관 / "읽지 말고 부딪혀 알기"
3. 대원칙: 엔진=일반형, 모드=제한된 설정 (전부 parameterizable)
4. 수치 투명성: 모든 값은 보정 가능한 기본값, `원본→현재` 병기

**전투 코어**
5. 전장: 아군 **4×4** 그리드, 적 기본 4×4(parameterizable, 6×6 등 가능)
6. 턴: 라운드제 기본(전원 1라운드 1행동), 라운드마다 SPD 주사위, 서열=상수/SPD. 스타레일 모드 후속
7. 타겟: 위치 마스크(사용가능칸+타겟칸), 칸 색 표시
8. 행동: 1턴 1행동. 스킬 **보유 x개 / 전투 활성 4개**
9. 데미지: 스킬 상수, ATK/DEF 없음, 속성 없음. 보정은 합연산만(곱연산=전역상태이상만). 순서 `(상수+합연산)×전역배율×crit`
10. 능력치: HP/SPD/DEX(회피)/명중률/crit%/crit배수 — 전부 보정 가능
11. 명중: (명중률+스킬명중)−DEX, 필중 플래그, 머리 위 명중% 표시
12. 방어: 오직 쉴드 레이어(상한 있는 덤 HP). HP피해 자체는 방어측이 못 줄임

**상태이상**
13. 통일 모델: 타임드 인스턴스 원장(스택+지속턴 분리, 출처 보존). 글랜스=스택/소멸턴/▾/추세, 호버=원장. 글랜스만으로 기본 플레이 충분
14. 전역: 화상(턴종료뎀)·중독(턴시작뎀)·출혈(행동시뎀)·마비(SPD↓)·동상(주는뎀×0.5)·빙결(행동불가)·공포(쉴드잠식 가속)
15. 특수: 관통(쉴드무시)·재생·불사(1턴 생존)·공위증(주는뎀 합연산+)

**캐릭터·육성**
16. 캐릭터: 클래스 없음, 포켓몬式 고유 디자인 + 작가 설계 learnset
17. 스탯=오직 장착(무기/방어구/지닌물건)으로만. 데미지=오직 스킬 획득·강화로만
18. 숙련도(영구 본체 레벨)=습득 가능 기술의 폭(tier) 해금. 스탯 안 올림
19. 판중 성장=전투 보상 화면(항상 기술 3택1: 새 스킬 or 강화/중첩). 범용 강화권=상점에서만
20. 스킬 강화=작가 설계 티어(Lv1→2→3)

**로그라이크 루프·런**
21. 기억 회랑 하이브리드: 본체 영구·안전, 출격은 사본, 판중 성장 휘발, 일부만 계승
22. 두 트랙 분리(하데스): 한 판 자기완결 + 영구 계승 별도 레이어. 계승=해금·자원 주력, 레벨 소량
23. 런: 분기 노드맵, 6노드(일반/엘리트/상점/인카운터/휴식/보스), 다층(기본 3층, parameterizable), 전멸=실패/최종보스=클리어, 웨이브=노드 내부 연속 파도

**포메이션 (차별점)**
24. 창발적 위치 효과: 열별 보너스 + 총량보존(몰빵vs분산). 일반전투=표준, 보스=기믹 변주. 적 진형보너스=보스전만
25. 동적 재배치=핵심 전술. 단 이동기 있는 유닛만 이동 가능

**엔진·인프라**
26. 아키텍처: 헤드리스 순수 코어 + 다중 뷰(텍스트/CLI=AI·모니터링 1급, 웹=사람 후순위)
27. AI는 스크린샷 아닌 구조화 관측+터미널로 플레이. 결정에 필요한 모든 정보가 observation에
28. 시드 기반 결정론 + 리플레이 + 이벤트 로그(= 애니메이션 구동원)
29. 스택=TypeScript 단일. 데이터 주도 설계 1급 원칙
