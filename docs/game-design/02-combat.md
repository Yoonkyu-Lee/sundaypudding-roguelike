## 2. 전투 — 코어

### 2.1 전장(Battlefield)

| 항목 | 결정 | 상태 |
|---|---|---|
| 형태 | 진형식 턴제 | ✓ |
| 좌표계 | **2D 그리드 `(행, 열)`** | ✓ |
| **아군 그리드** | **4열 × 4행 (16칸) 확정.** 파티 ≤4명을 이 안에 배치 | ✓ |
| **적 그리드** | **기본 4×4, parameterizable.** 적 수는 4일 필요 없음 (예: 6×6에 36마리도 가능) | ✓ |
| 단순/기본 표시 | 기본 예시는 4 vs 4, 단 양측 그리드·적 수는 가변 | ✓ |
| 일반화 | 대원칙 0.1: 엔진은 임의 그리드, 모드가 제한 | ✓ |

- **아군 전장은 4×4 그리드로 확정**(파티 ≤4명 배치). 한 줄로 세우는 것도 가능하지만 격자 자체는 4×4 — 포메이션(6장)이 여기서 작동.
- 멘탈 모델은 **포켓몬 트리플 배틀**(늘어선 유닛 + 위치/인접성이 의미를 가짐)에서 출발, 4×4 + 열보너스로 확장.

### 2.2 턴 순서 (라운드제 — 기본 모드)

| 항목 | 결정 | 상태 |
|---|---|---|
| 기본 모드 | **라운드제**: 한 라운드 = 모든 유닛이 정확히 1번씩 행동 | ✓ |
| 서열 결정 | 라운드 초기화 때마다 각 유닛이 **자기 SPD 범위에서 주사위**를 굴려 이번 라운드 SPD 확정 | ✓ |
| 정렬 | 행동 서열 = `행동수치 / SPD` → **SPD 높을수록 먼저** 행동 | ✓ |
| 모듈화 | 턴서열은 교체 가능한 모듈(`TurnOrderResolver`). **스타레일식 연속 타임라인(빠르면 더 자주)**은 별도 모드로 후속 구현 | ✓ |

- `행동수치`(분자)는 공통 상수로 가정(예: 10000). → `상수 / SPD`가 작을수록 먼저. ☐ 정확한 상수값 후속.
- 노트의 `R / R2`는 **라운드 1, 라운드 2** 의 행동서열 표였음(속성/랭크 아님).

### 2.3 행동 경제 & 스킬 슬롯

| 항목 | 결정 | 상태 |
|---|---|---|
| 한 턴 행동 | **여러 선택지 중 1개만 실행 = 턴 종료** (포켓몬식) | ✓ |
| 보유 스킬 | 유닛당 최대 **`x`개 보유**(4.2) | ✓ |
| 전투 활성 슬롯 | **전투 전 4개 선택**, 전투 중 고정 | ✓ |

> 의사결정이 "**무슨 스킬을, 누구에게**" 둘로 압축된다. (보유 풀에서 4개를 고르는 건 전투 전 단계 — 4.2/4.5 참조)

### 2.4 타겟팅 — 위치 마스크

| 항목 | 결정 | 상태 |
|---|---|---|
| 표현 | 스킬마다 **2개의 위치 마스크**: `사용가능 칸 집합` + `타겟 칸 집합` (2D 그리드 좌표) | ✓ |
| 일반성 | 포켓몬식 인접 규칙·근접/원거리는 모두 마스크로 표현 가능(마스크가 상위집합) | ✓ |
| 표시 | 화면에 **칸 색으로 표시**(예: 사용가능=파랑, 타격=빨강). 글 안 읽고 칸 색만 봐도 이해 | ✓ |

### 2.5 데미지 모델

| 항목 | 결정 | 상태 |
|---|---|---|
| 데미지 | **스킬에 박힌 상수(flat).** 공격력/방어력 능력치 **없음** | ✓ |
| 보정 | 버프/디버프/상태이상/특수효과가 반감·증폭 가능 | ✓ |
| 표시 | 보정 시 **`원본 → 현재` 병기** (예: `30 → 45`, `30 → 15`) | ✓ |
| 속성/타입 | **현재 없음** (필요해지면 대원칙대로 후속 확장) | ✓ |

### 2.6 능력치 (Stats)

> 전부 **보정 가능한 기본값**이다. 절대불변 고정값 아님. 보정 시 `원본 → 현재` 병기.

| 능력치 | 역할 | 기본/비고 | 상태 |
|---|---|---|---|
| **HP** | 체력. 0이면 전투불능 | 유닛 고유 | ✓ |
| **SPD** | 라운드 행동서열 결정 | 유닛 고유 **범위**(예: 4~7), 매 라운드 주사위 | ✓ |
| **DEX (민첩)** | **회피**. 높을수록 안 맞음 | 유닛 고유 | ✓ |
| **명중률** | 명중 판정에 가산 | 유닛 **기본 0** + 스킬에 내장된 명중률 | ✓ |
| **crit%** | 치명타 확률 | 기본 **10%** (보정 가능) | ✓ |
| **crit 배수** | 치명타 시 데미지 배수 | 기본 **×1.5** (보정 가능) | ✓ |

- **공격력/방어력 능력치는 없다.** 데미지는 스킬 상수.

### 2.7 명중 판정

| 항목 | 결정 | 상태 |
|---|---|---|
| 공식 | `실제 명중% = (공격자 명중률[기본0+보정] + 스킬 명중률) − 타겟 DEX` (0~100% 클램프) | ✓ |
| 필중 | 일부 스킬은 공식을 무시하는 **"필중" 플래그** 보유 가능 | ✓(개념 채택) |
| UI | 대상 지정 시 **실제 명중%를 적 머리 위에 표시** → 플레이어는 회피율 계산 불필요 | ✓ |

### 2.8 치명타

| 항목 | 결정 | 상태 |
|---|---|---|
| 판정 | 공격자 `crit%`로 굴림 → 성공 시 데미지 `× crit배수` | ✓ |
| 표시 | 데미지 병기 규칙 동일 (예: `30 → 45`) | ✓ |

### 2.9 방어 = 쉴드(Shield)

| 항목 | 결정 | 상태 |
|---|---|---|
| 개념 | **받피감%가 아니라 쉴드.** 상한이 있는 **임시 추가 체력(덤 HP)** | ✓ |
| 동작 | 피해는 **쉴드부터** 깎고, 쉴드가 0이 되면 HP를 깎음 | ✓ |
| 부여 | 능력치가 아님. 버프/효과로 부여 | ✓ |
| 표시 | HP 바 위에 **다른 색 칸**으로 표시(보이는 방어) | ✓ |
| 상세 | 상한값/지속/중첩 규칙 | ☐ 후속(상태이상 챕터에서) |

### 2.10 스킬 쿨타임(cooldown)

| 항목 | 결정 | 상태 |
|---|---|---|
| 분담 원칙 | **메커니즘=엔진, 값=스킬 데이터** (데미지·상태이상과 동일 패턴, 8.6) | ✓ |
| 쿨타임 값 | 스킬마다 선언 (예: "쿨타임 3") | ✓ |
| 엔진 책임 | 유닛별·스킬별 **잔여 쿨타임 추적 + 감소 + 사용 차단** | ✓ |
| **모니터링** | 쿨타임 잔여 = **관측(observation) 1급 필드.** `getLegalActions()`는 쿨다운 중 스킬을 자동 제외 | ✓ |
| **단위·감소** | **그 유닛의 턴 단위.** 쿨타임 3 = 사용 후 그 유닛의 다음 3턴 잠금, 4번째 턴에 재사용. 유닛의 턴이 올 때마다 1 감소 | ✓ |
| **전부 쿨다운 폴백** | **기본 공격 없음.** 효과 없는 **스킵(패스)**으로 턴을 넘긴다. 단 **"지금 쓸 수 있는 기술 없음"을 명확히 알림** (허비된 턴 = 쿨타임 관리 실패 페널티) | ✓ |
| **리셋 범위** | **웨이브 사이엔 유지**(한 노드=연속 전투), **노드(전투)가 바뀌면 리셋** | ✓ |

### 2.11 끼어들기(interrupt) — 서열에 비집고 드는 번외 행동

> 스타레일 "추가 턴"의 문제: "턴"이라 부르면 "쿨다운/지속시간이 도는 정규 턴"으로 오해되어 매번 각주가 필요.
> 우리는 **이름·연출·관측이 "정규 턴 아님"을 구조적으로** 말하게 해서 각주를 없앤다.

| 항목 | 결정 | 상태 |
|---|---|---|
| 명칭(도메인) | **「끼어들기」** (영문 `interrupt`). "행동 서열에 비집고 끼어든 1회 행동" — 추후 변경 가능(난입/새치기 등 후보) | ✓ |
| 발동 | 캐릭터 특성/스킬이 발동시킴. 행동 서열에 **동적 삽입**되는 1회 행동 | ✓ |
| **출처 일반화** | 끼어들기는 **스킬에 국한되지 않음.** 출처 = ① 스킬(`grantsInterrupt`) ② 버프/상태(`grantsInterrupt`, 예: 신속) ③ 향후 캐릭 특성. 실행·미리보기가 **단일 함수 `predictInterruptSubjects`** 공유 | ✓ |
| **주체(subject)** | 끼어들기 주체가 **행동자 본인이 아닐 수 있음.** `grantsInterruptTo: self\|target` — 서포트(재촉)는 **대상 아군**이 끼어들기 | ✓ |
| 발동 조건 | **정규 턴 행동 시에만** 발생(끼어들기 턴은 연쇄 방지로 제외) | ✓ |
| 예고(웹) | 타겟팅 중, 삽입 위치에 **유령 칸이 밖→안 슬라이드+깜빡 + 끼어들기 "주체 이름" 표시**(서포트면 다른 캐릭). "예고" 텍스트 없이 초록 모션만으로 전달 | ✓ |
| **핵심 규칙** | 끼어들기는 **쿨타임·지속시간을 차감하지 않는다.** 모든 차감은 **정규 턴 기준** | ✓ |
| 주기 효과 | **화상(턴 종료)·중독(턴 시작)은 정규 턴만 기준** (끼어들기 횟수와 무관) | ✓ |
| **출혈 예외** | **출혈은 정규 턴 + 끼어들기 턴 — 모든 "행동 시" 발동**(끼어들기 남발의 카운터). 단 **출혈 지속시간 차감은 정규 턴만** | ✓ |
| 연출 | 서열 바에서 **정규 턴 사이가 벌어지며**, 더 넓고 튀어나온 **초록 하이라이트 토큰**이 삽입됨 | ✓ |
| 관측 | `actionOrder` 항목에 `kind: "normal" \| "interrupt"` 플래그 → 사람 연출과 동일 정보를 기계에도(8.2) | ✓ |
