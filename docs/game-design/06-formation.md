## 6. ★ 포메이션 변주 시스템 (차별점)

> 방식: **창발적 위치 효과(A2)** — 명명 진형 프리셋(A1) 아님. "어디 서 있는지 자체"가 효과를 만든다.

### 6.1 핵심 메커니즘 — 열(column)별 보너스 + 총량 보존

| 항목 | 결정 | 상태 |
|---|---|---|
| 단위 | **각 열(column)이 고정된 "보너스 총량"을 제공** | ✓ |
| 분배 | 그 총량은 **해당 열에 선 유닛 수로 나눠 분배(총량 보존)** | ✓ |
| 효과 | 몰빵(1명=전부) vs 분산(N명=각 1/N)의 트레이드오프가 **위치만으로** 발생 | ✓ |
| 표시 | 각 유닛이 받는 실제 보정은 그 자리에 병기(수치 투명성 0.2) | ✓ |

**예시** (열 보너스 배치):
```
1열: 공격 스킬 위력 +4      3열: 방어 스킬 위력 +4
2열: 공격 스킬 위력 +4      4열: 방어 스킬 위력 +4
```
- 4열에 3명 → 각자 방어스킬위력 +4/3
- 4열에 1명 → 그 1명에게 +4 몰림

### 6.2 그리드

- **아군 4×4 확정** (2.1). 한 열에 최대 4명까지 겹쳐 설 수 있음 → 총량보존 트레이드오프 성립.
- **적 기본 4×4, parameterizable** (2.1).

### 6.3 변주의 원천 — 표준 vs 보스 기믹

| 항목 | 결정 | 상태 |
|---|---|---|
| 일반 전투 | 열 보너스 배치가 **통일된 표준**으로 적용 | ✓ |
| 보스/특수 | **보스 기믹으로 진형 효과 변경** (디자이너 자유 설계) — "변주"가 여기 집중 | ✓ |
| 적 진형 보너스 | **기본 미적용**(일반 적은 배치만). **보스전에만** 적 진형 보너스 적용 | ✓ |

### 6.4 동적 재배치 (핵심 전술)

| 항목 | 결정 | 상태 |
|---|---|---|
| 격상 | 밀치기/끌기/자리바꿈으로 적·아군을 다른 열로 옮기는 것을 **핵심 전술로 격상** | ✓ |
| **이동 규칙** | **이동기(스킬)를 가진 유닛만 이동 가능. 이동기가 없으면 그 캐릭은 못 움직인다** | ✓ |
| 도입 | 점진적 — 처음엔 일부 스킬만 이동 효과 겸비 | ✓ |
| 시너지 | 위치 마스크(2.4) + 열보너스(6.1) + 보스 진형 기믹(6.3) | ✓ |
