# 야인시대 — 마스터 캐릭터 리스트 (초상화 수집용 체크리스트)

> **목적**: 야인시대 팬게임에 등장하는 모든 캐릭터를 한 곳에 모아, **캐릭터별로 실제 사진(초상화)을 구해오기 위한 체크리스트**로 쓴다.
> **범위**: `docs/Yainsidae/gamedata/run01~run08`의 **플레이어 파티** + **적 캐릭터 (로스터)** 섹션에 실제 게임 유닛(플레이어/보스/엘리트/적/NPC)으로 등장하는 인물 + `chapters/ch01~ch08`로 소속·진영·실존여부 보강. **chapters에만 언급된 순수 역사 배경 인물(게임 유닛 아님)은 제외**.
> **읽는 법**: 같은 인물은 한 행으로 합치고 등장 런을 전부 표기. 단, 김두한처럼 시대별 외모차가 큰 인물은 **초상화가 여러 장 필요하므로 행을 나눴다**(비고에 명시). **구현 현황**: ✅ = 이미 `web/src/content/characters.ts`에 id 있음 / ☐ = 미구현. **실존/가명**: 실존 = 사진 구하기 쉬움 / 가명 = 드라마(SBS 야인시대) 배우 스틸 또는 대체 이미지 필요 / 불명 = 확인 안 됨.

**초상화 필요 총계: 약 88종** (중복 제거 후 인물 약 84명, 김두한 3장 + 정진영(소년/장년) 분리로 시대 변형 +4장 가산 ≈ 88장).

> 주의: 「실존/가명」은 야인시대 등장 인물의 성격 판단이며(실존 = 역사 실인물, 가명 = 드라마 창작/예명/별명 캐릭터), 사진을 어디서 구할지 결정하는 용도다.
