# Yainsidae — 야인시대 대본 지식베이스 (팬게임 콘텐츠 원천)

이 게임은 **야인시대 팬게임**. 드라마 풀 대본(124화)을 파싱·요약해 **캐릭터·전투 스킬·패시브·런 설계의 원천**으로 쓴다. (현 게임 데이터의 스킬/패시브는 상상 기반 placeholder — 이 지식베이스로 추후 전면 교체 예정.)

## 파이프라인 (3층)

1. **`summaries/`** — 회차별 요약(124개). 각 회차 대본을 읽고 **등장인물·주요 행적·세력/관계·테마**를 정리. (`epNNN.md`)
2. **`chapters/`** — `summaries`를 **시기별 큰 단위로 분류·인덱싱**. 단위마다 세력·인물 관계(동료/윗사람/부하/적)·행적·테마 정리. (아크 단위)
3. **`gamedata/`** — `chapters` 기반 **런 설계도**(런 당 1문서). "이 세력 vs 저 세력 = 엘리트 노드, 적 로스터·스킬·컨셉·다음 노드…" 식으로 게임화 청사진.

→ 이 문서들이 캐릭터/스킬/패시브/런 **구현의 설계 입력**이 된다.

## 원천 데이터
- `docs/야인시대 *.xlsx` (통합대본) — 시트1 = 회차·시간·인물·대사. 나레이션·상황·장소·사물·행동 지문까지 포함(영상 없이 시청 수준).
- **`_raw/`** = xlsx에서 추출한 회차별 텍스트(`epNNN.md`). **gitignore(파생물)** — `_tools/parse-script.mjs`로 재생성.

## ★ 공통 프리미티브 갭 (8개 런이 독립적으로 수렴 — 콘텐츠 전면 교체 시 엔진 설계 입력)
런 설계 에이전트들이 일관되게 같은 "현 엔진으로 원자적 표현 불가" 메커니즘을 지목했다(데이터-온리 근사는 가능, 원작 충실엔 엔진 확장 권장):
1. **summon(소환)** — 전투 중 임시 아군 생성(개코 거지패·세력 증원·군중 동원). 현 SkillEffect엔 없음. → 엔진 프리미티브 후보.
2. **런 자원 게이지(민심/명분)** — 전투 외부 영속 자원 + 노드/전투 모디파이어 훅(약자 보호·연설로 충전, 기습·총기로 감소 → 복속·심리전·부활 강도에 영향). 후반 아크에선 **정치/선거/여론** 메커니즘으로 확장.
3. **게이지-비례 효과·심리전 판정** — 위 자원에 종속(부활 강도·무혈 굴복 등).
> 이 셋은 콘텐츠 교체(스킬·패시브·런 전면 재작성) 착수 시 `/slice-plan` 프리미티브-갭 프로토콜로 판정·승인 대상. 데이터-온리 대안(자버프·진형 사전배치·event 플래그·확률)으로 v1 근사 가능.
