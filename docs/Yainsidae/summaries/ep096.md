# 야인시대 96화 요약

## 한 줄
이정재 사단이 자유당 당의장 선거를 폭력으로 장악하고, 자유당이 김관철 살인미수 혐의를 조작해 당선 직후 김두한을 구속시키며, 이정재 측이 마침내 시라소니를 직접 "깨겠다"고 결의한다.

## 등장인물
- 시라소니 — 이영숙 요정 격투 마무리 후 황성옛터 부르며 퇴장, 이정수와 귀가; 칠성을 통해 이정재에게 노점 자리·500만환 재차 요구
- 이영숙 (동대문 조선관 오야붕) — 패배 인정, 김동진과 동대문 이탈 공모 심화, 이정재에 불만 고조
- 김동진 (동대문 이탈 직전) — 이영숙과 다시 대화, 이정재의 전횡을 비판하는 이영숙의 제안에 암묵적 동의 후 퇴장
- 이정재 (동대문 회장 / 자유당 감찰부 차장) — 자유당 당의장 선거 방해 지시, 시라소니 처리 여부 고민
- 이석재 (동대문 간부) — 자유당 당사에서 이갑성 측 당원 납치·구타, 김상도와 직접 충돌
- 이억일 (동대문 간부) — 김상도 제지 시도, 역으로 날아가 착지
- 김기홍 (동대문 고문) — 당의장 선거 작전 지휘, 시라소니 "깨야 한다" 강력 건의
- 이기붕 (자유당 이인자) — 당의장 선거 연설, 이갑성 측 혼란 무시하고 당선
- 이갑성 (자유당 당의장 경쟁자) — 동원 당원들이 납치·구타당해 의사 정족수 붕괴, "선거 무효" 외침
- 김상도 (이갑성 측 호위대장 / 별명 금호장군) — 동대문패 저지 시도, 이석재와 격투 후 이억일을 날려버리며 선전했으나 쪽수에 밀려 패배·당사 난입 연설 뒤 구타당함
- 한백수 (이기붕 비서실장) — 종로 경찰서 김형사에게 지시, 김두한 체포영장 획책
- 김형사 (종로 경찰서) — 김관철을 압박해 허위 고소장 작성 시도, 실패하자 조서 위조 지시 받음
- 김관철 — 형사의 고소장 날인 거부, "목에 칼이 들어와도 큰형님 배반 못 한다" 유치장 수감
- 김두한 (무소속 당선 의원) — 정대발·채원기를 보좌관으로 맞이, 한백수의 자유당 입당 요구를 식탁 치며 거부, 살인미수 혐의로 구속
- 조병옥 (야당 민국당) — 두한 구속을 "음모정치의 시작"으로 규정
- 이기붕 / 박마리아 — 개헌·무소속 영입·영구집권 전략 논의
- 유지광 (설봉사) — 현도스님과 대화, "세상에 내려갈 때가 됐다" 암시 받음; 이억일이 데리러 파견 예정
- 현도스님 — 유지광에게 "앞길이 험할 것"이라 예언 후 하산 권유
- 임화수 — 이기붕에게 "인테리" 칭찬 받은 것에 감격, 영어 공부 결심; "임화수의 시대가 온다" 독백

## 주요 행적 (시간순)
1. 시라소니가 이영숙 요정 부하 전원 제압 완료 (96화 오프닝은 95화 격투 마무리) — 총 두 번 무력화, 고릴라 박치기, 다수 격투, 유유히 퇴장
2. 이영숙이 김동진에게 "동대문 이탈·이정재 타도" 재차 제안, 김동진 암묵 동의 후 퇴장
3. 이정재가 곽영주 전화로 자유당 동대문 지구당위원장 내정 소식 들음
4. 임화수가 이기붕의 "인테리" 칭찬을 거듭 회상, 영어 공부 결심, "찬스가 온다!" 독백
5. 이기붕·박마리아가 개헌 전략 논의 — 무소속 영입 필요, 김두한 회유 먼저 시도 결정
6. 한백수가 두한에게 전화 — 조선관 저녁 자리 요청
7. 두한이 보좌관 정대발(김영태 추천)·채원기(최동열 추천) 영입
8. 한백수가 두한에게 자유당 입당 요구, 두한이 식탁을 치며 거절 "야당이다, 차라리 형무소 택하겠다"
9. 한백수가 종로 경찰서에 지시 — 과거 두한의 공포탄 사건을 "김관철 살인미수"로 조작
10. 종로 경찰서에서 김관철에게 고소장 날인 강요, 김관철 완강 거부 후 유치장 수감
11. 한백수가 "조서 위조해서 영장 바로 발부시켜라" 지시
12. 자유당 당사 — 이석재 선두부대가 이갑성 측 당원들을 사전 납치·구타, 입장 봉쇄
13. 당사 내부 — 김상도가 이석재와 격투(선전), 이억일을 날려버림; 쪽수에 밀려 결국 제압
14. 이기붕이 김상도의 항의를 무시하고 당의장 선거 강행, 거수 투표로 압도적 당선
15. 나레이션: "김상도 테러사건 — 이기붕-이정재 결탁의 첫 정치테러사건"으로 규정
16. 경찰이 두한 사무실에 난입, 김관철 살인미수 체포영장으로 구속
17. 두한: "자유당이 선전포고한 것" 담담히 수용, 거부 선언
18. 설봉사 — 유지광이 수련 중, 현도스님 "내려갈 때가 됐다" 권유; 이정재가 이억일을 유지광에게 파견하기로 결정
19. 칠성이 이정재에게 시라소니의 노점·500만환 요구 편지 전달
20. 이석재·김기홍이 "시라소니를 깨야 한다"고 이정재에게 강력 건의
21. 이정재가 "시라소니를 직접 오라 하라"고 결정 — 시라소니와의 대결 예고

## 세력·관계
- 이정재·이기붕 ↔ 이갑성·김상도: 적대 — 정치테러로 당의장 선거 장악
- 자유당(한백수) ↔ 김두한: 적대 격화 — 조작 혐의로 구속, "자유당 아니면 감옥"
- 이정재 → 시라소니: 갈등 임박 — "직접 오라" 소환, 격돌 직전
- 이정재 → 유지광: 영입 추진 — 이억일 파견 확정
- 이영숙 ↔ 김동진: 잠재 동맹 — 이정재 타도 공조 심화

## 테마·분위기
- 정치 폭력의 제도화: 이기붕-이정재 결탁이 자유당 당의장 선거를 노골적 폭력으로 결정짓는 첫 사례
- 김두한 수난의 시작: 당선 직후 조작 혐의로 구속, 야당 의원의 고립감
- 시라소니와의 충돌 예고: "전설은 깨어져야 새 전설이 생긴다"는 김기홍의 논리로 대결 합리화
- 유지광 하산 준비: 강력한 새 인물이 정치 주먹판에 합류하기 직전
