# 야인시대 37화 요약

## 한 줄
마루오까가 두한을 무사도 정신으로 석방하고 의형제를 맺으며, 두한은 하야시에게 시장 계약 파기를 선언한다.

## 등장인물
- 김두한 (우미관 오야붕) — 마루오까 유도장 심판, 석방 후 마루오까와 의형제, 하야시에게 계약서 찢어 돌려보냄
- 마루오까 (종로서 경부) — 유도장에서 두한을 공개 심판하여 무죄 방면, 의형제 제안
- 미와 (고등계 경부) — 두한 석방 소식에 분노, 마루오까와 충돌
- 하야시 (혼마찌 오야붕) — 두한의 계약 파기 선언을 받고 전면전 명령
- 나미꼬 (사쿠라 사장) — 형부 하야시에게 두한 구명을 청했으나 거절당함
- 김영태 (우미관 보좌) — 시장 상황 보고, 하야시와의 전면전 우려
- 정진영 (우미관) — 하야시 나와바리에 전갈 전달
- 정운경 (민간인) — 설향에게 청혼, 두한을 직접 찾아와 설향에 대한 뜻 확인
- 설향 (권번 기생) — 정운경의 청혼 답변 유예, 두한에게 미련
- 애란 (권번) — 설향에게 정운경 수락 권유
- 박인애 (이군의 아내) — 술 취한 이군에게 구타당함
- 최동열 (잡지사) — 일본군 행진을 보며 식민지 현실 비판
- 가미소리 (혼마찌 부두목) — 하야시로부터 전면전 전권 위임

## 주요 행적 (시간순)
1. 마루오까가 조사실에서 두한을 심문; 두한은 비겁한 싸움이 아님을 주장
2. 나미꼬가 형부 하야시를 찾아가 두한 구명 청원 — 하야시는 "적"이라며 거절, 사업 개입 금지 경고
3. 마루오까가 유도장에 두한을 세워 제자들의 공개 심판 → 전원 "무죄" 판정 → 석방
4. 마루오까가 설렁탕집에서 두한과 동석; 패배를 인정하고 의형제 제안 → 두한 수락
5. 미와가 마루오까의 석방 결정에 격분, 뇌물 의혹 제기 → 마루오까 단호히 일축
6. 우미관패들이 종로회관에서 마루오까와 처음으로 합석, 어색하지만 화해 분위기
7. 하야시가 마루오까-두한 의형제 소식을 듣고 두한을 "무서운 자"로 재평가
8. 두한이 김영태에게 이정목 시장 침식 실태 보고 받음 — 하야시패 상인들이 조선 상인 점포 강탈
9. 두한이 상인들에게 가게 되찾아 주겠다고 약속, 혼마찌로 전갈 보냄
10. 정운경이 우미관을 방문해 두한에게 설향에 대한 자신의 뜻 밝힘 → 두한은 물러서라는 뜻 전달
11. 정진영이 혼마찌를 방문해 하야시에게 회담 제안 → 약속 성사(다음날 저녁 사쿠라)
12. 사쿠라 회동: 두한이 계약금을 돌려주고 계약서를 찢음 → 하야시 "전면전" 선포
13. 이군이 만취 귀가 후 박인애 폭행

## 세력·관계
- 김두한 ↔ 하야시: 적대 → 전면전 선포 (계약 파기 사건)
- 김두한 ↔ 마루오까: 적대 → 의형제 (무사도 상호 인정)
- 마루오까 ↔ 미와: 적대 (석방 결정 충돌)
- 하야시 → 가미소리: 상하 (전면전 전권 위임)
- 나미꼬 ↔ 하야시: 상하(윗사람), 나미꼬의 청원 거절
- 두한 ↔ 정운경: 처음 만남, 설향을 두고 서로 물러섬

## 테마·분위기
- 무사도와 협객 정신의 역설적 충돌: 일본 경찰 마루오까가 조선 건달을 무사도로 인정
- 종로 조선 상인과 혼마찌 야쿠자의 경제적 수탈 갈등이 전면전으로 비화
- 식민지 일상의 잔혹: 일본군 행진에 일장기 흔드는 조선인, 친일 인사 비판
- 사랑과 현실: 설향-두한-정운경 삼각 구도, 박인애의 비참한 결혼 생활
