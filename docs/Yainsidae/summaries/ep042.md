# 야인시대 42화 요약

## 한 줄
두한이 부하들의 고문을 견디다 못해 스스로 헌병대에 자수하고, 번개는 전기 고문으로 사망한다.

## 등장인물
- 김두한 (종로 우미관패 두목) — 암자에 피신; 부하들 걱정에 홀로 하산, 헌병대에 자수
- 김영태 (우미관 고문) — 설향에게 두한 도피 메시지 전달; 헌병대에 체포되어 고문 당함; 번개 사망을 눈앞에서 목격
- 번개 (우미관패) — 헌병대에서 고문 끝에 사망
- 정진영 (두한의 동료) — 두한과 함께 암자에 피신; 거지로 변장해 종로 탐문; 최동열에게 통행증 요청
- 설향 (기생) — 김영태로부터 메시지 받아 암자로 전달; 두한의 탈출을 간곡히 권유; 통행증 수령 역할 맡음
- 김무옥, 문영철, 와싱턴, 개코 (우미관패) — 우미관에서 헌병대에 끌려가 고문 당함
- 헌병대위 — 취조·고문 집행; 번개를 고문으로 죽게 함
- 미와 (종로서 고등계 경부) — 사태를 관망; 헌병대의 강압 수사에 은근히 부러움 표시
- 마루오까 (종로서 경부) — 관찰자로 등장
- 하야시 (혼마찌깡 오야붕) — 두한에 대해 안타까워하며 도울 의사를 내비침
- 최동열 (잡지사장) — 중국행 통행증 주선 약속
- 왕눈이·깍두기 (거지촌) — 진영의 변장 활동 보조

## 주요 행적 (시간순)
1. 두한과 진영이 산길을 뚫고 경성 외곽 암자로 피신한다.
2. 헌병이 종로를 장악하고 우미관패를 모조리 연행한다.
3. 김영태가 설향에게 두한의 도피 메시지(만주·중국으로 탈출하라)를 전하고 체포된다.
4. 헌병대에서 김무옥·와싱턴·번개·개코에게 두한 행방을 캐묻는 고문이 자행된다.
5. 번개가 전기 고문으로 사망한다. 헌병대위는 화장으로 증거를 인멸하라고 지시한다.
6. 김영태는 전기 고문을 받으면서도 끝까지 두한의 소재를 발설하지 않는다.
7. 설향이 암자에 올라가 두한에게 탈출을 권한다. 두한은 갈등한다.
8. 진영이 거지로 변장해 종로를 탐문, 최동열에게 통행증을 부탁한다.
9. 두한이 밤중에 암자를 몰래 빠져나와 부하들을 위해 홀로 남산 헌병대에 자수한다.
10. 헌병 보초에게 "김두한이 왔다"고 밝히며 연행된다.

## 세력·관계
- 두한 ↔ 헌병대: 추격-도주 → 자수 (결정적 대결 국면)
- 번개 ↔ 헌병대위: 피해자-가해자 (고문 사망)
- 김영태 ↔ 헌병대: 체포·고문, 끝까지 침묵
- 하야시 ↔ 두한: 적대에서 화해·배려 구도 (하야시가 구명 의사 표명)
- 설향 ↔ 두한: 설향이 목숨 걸고 전령 역할 수행
- 미와 ↔ 헌병대: 사건 처리 관망, 내심 부러움

## 테마·분위기
- 의리와 자기희생: 번개의 죽음, 김영태의 침묵, 두한의 자수가 모두 동료를 위한 선택
- 고문과 잔혹: 헌병대 취조실의 전기·물·매질 고문이 사실적으로 묘사됨
- 결단의 순간: 도주냐 자수냐 — 두한은 종로를 버릴 수 없다는 신념으로 스스로 죽음의 문을 두드림
- 무력한 조력자들: 종로 유지, 마루오까, 최동열 등이 도우려 하나 군사권력 앞에 한계를 느낌
