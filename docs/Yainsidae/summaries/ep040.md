# 야인시대 40화 요약

## 한 줄
혼마찌와의 화해가 성립되고 가미소리가 할복 자결하는 가운데, 두한은 창씨개명을 거부하고 만담가 신불출을 만나 새로운 세상에 눈을 뜬다.

## 등장인물
- 김두한 (우미관 오야붕) — 병원에서 하야시와 화해, 고노에 만찬 참석, 창씨개명 거부, 신불출과 교류
- 하야시 (혼마찌 오야붕) — 두한에게 패배 인정 직접 고백, 고노에 주선으로 화해 협상
- 고노에 (하야시 장인, 야쿠자 원로) — 화해 주선, 남대문 자전거 보관소·월 천원 세금 상납 조건 제시
- 가미소리 (혼마찌 부두목) — 하야시 앞에서 책임 자처 후 할복 자결(미우라가 목침)
- 나미꼬 — 두한에게 자신이 계략을 꾸몄음을 고백하고 일본으로 출국
- 시바루 — 나미꼬를 배웅하며 이별, 감정 고백
- 마루오까 (종로서 경부) — 두한 병원 방문, 하야시에게도 두한 칭찬
- 김영태 (우미관 보좌) — 고노에 정체 설명, 시장 단속 강화 약속
- 신불출 (만담가) — 우미관 공연에서 창씨개명 풍자, 두한과 첫 만남·사회주의 사상 전달
- 박인애 — 유산 후 퇴원, 두한 소식에 안도
- 정운경 — 설향에게 일본행 동행 제안, 거절당하고 출발
- 미와 (고등계 경부) — 신불출 공연에 경고, 두한에게 감시 선언
- 일가사내들 — 두한에게 창씨개명 권유하러 왔다가 쫓겨남

## 주요 행적 (시간순)
1. 하야시가 두한 병원에 단독 방문, "내가 졌다 — 처분을 따르겠다" 선언
2. 두한이 "싸움은 끝나지 않았다"며 하야시를 돌려보냄 (화해도, 항복도 아닌 유보)
3. 가미소리가 하야시에게 전말을 자백하고 할복 자결 → 미우라가 목을 쳐 마무리
4. 임동호가 박인애의 유산을 가족에게 통보; 이군 충격
5. 고노에가 나미꼬에게서 두한 아버지가 김좌진 장군임을, 또 김옥균의 일가임을 확인
6. 고노에가 두한을 저녁식사에 초대 → 두한 수락
7. 일가사내들이 두한을 찾아와 창씨개명 권유 → 두한 분노하며 쫓아냄
8. 나레이션: 창씨개명 실태 설명 (거부 시 식량·기차표 불이익)
9. 고노에 만찬: 김옥균과의 인연 소개, 혼마찌와 평화 공존 제안 — 월 천원 세금 + 남대문 자전거 보관소 양도
10. 두한이 조건을 거절("받을 이유 없다")하되 "더 이상 종로를 넘보지 않는다면 싸우지 않겠다" 수락
11. 나미꼬가 두한에게 계략을 자백 및 고별 인사 → "당신을 영원히 잊지 못할 거예요" → 일본 출국
12. 시바루가 나미꼬를 배웅, 감정을 억제한 이별
13. 두한이 종로 시장 방문, 전쟁 여파로 어려워진 상인들을 위해 세금 면제 선언
14. 헌병 스즈끼가 인력거꾼을 채찍질 → 두한이 개입하려 하나 진영이 제지
15. 우미관에서 신불출 만담 공연 — 창씨개명 '축생' 풍자 → 미와가 경고
16. 두한이 신불출과 첫 만남: "무산대중의 영웅" 칭호, 사회주의 사상 첫 접촉
17. 신불출이 친일 연극 "등불"을 고발 → 두한이 "이 김두한이가 있는 한 절대 못 한다" 선언

## 세력·관계
- 김두한 ↔ 하야시: 적대 → 사실상 화해 (하야시의 자발적 패배 인정)
- 김두한 ↔ 고노에: 첫 만남, 경계심 속 상호 인정
- 나미꼬 → 김두한: 적대에서 고별로 마무리, 일본 출국으로 퇴장
- 가미소리 → 하야시: 충복 최후, 할복으로 책임
- 두한 ↔ 신불출: 새 동료 관계 시작 (나중에 조선청년전위대 결성 복선)
- 미와 ↔ 두한: 지속적 적대·감시

## 테마·분위기
- 승자의 아량과 패자의 품위: 두한은 가혹한 처분 대신 공존을 선택
- 식민지 압박의 일상화: 창씨개명 강요, 헌병 채찍질, 친일 연극 기획
- 정체성 투쟁: 두한의 창씨개명 거부가 아버지 김좌진의 민족정신을 잇는 행위로 연결
- 새로운 지평: 신불출과의 만남이 두한을 '무산대중의 영웅'이라는 정치적 맥락으로 인도
- 이별과 전환: 나미꼬 퇴장, 가미소리 자결로 혼마찌 갈등 챕터가 완전히 닫힘
