# 런 8: 4.19와 최후 (원작 121~124화)

## 컨셉 (이 아크 → 런)
야인시대 최종장이자 **드라마 전체의 종막**을 한 런으로 압축한다. 핵심 정체성은 "주먹의 시대가 끝나고, 두한 한 사람도 소멸한다" — 그래서 이 런은 **승리하면서도 점점 잃어가는 비극형 런**이다. 4개 층으로 구성하며, 층이 진행될수록 전투형에서 비전투(결단·버티기·자폭 연출)형으로 무게가 옮겨간다.

- **1층 — 부정선거와 4.19 (121화)**: 거리 전투 중심. 반공청년단 주먹 vs 학생/시위대. 가장 정통 로그라이크 전투층. "학생 보호" 분기 선택이 핵심.
- **2층 — 하야와 혁명재판 (122~123화)**: 권력 붕괴와 청산. 발포 라인 엘리트 → **혁명재판(비전투 결단 보스)**. 동료(이정재·유지광)의 생사가 플레이어 선택으로 갈린다. 잃음의 시작.
- **3층 — 방황과 재기 (123화)**: 메타/회복층. 애국단 도박 이벤트(이용당할 위험) → 동지의 회상으로 재기 버프 → 용산 보궐 유세. classChange(한독당 재건=두한 전직) 노드 배치.
- **4층 — 최후 (124화)**: **중정 고문 버티기 보스** → **국회 똥통 투척(연출 클라이맥스)** → 참회와 죽음(엔딩 데코 노드). 전투보다 "버티고, 한 방 던지고, 진다"는 정서가 지배한다.

전투 보상이 누적되지만 동시에 파티가 줄어드는(동료 처형·이탈) **양날 구조**가 이 런의 시그니처. 마지막 보스는 적을 죽여 이기는 게 아니라 **굴복하지 않음 자체가 승리**다.

## 플레이어 파티 (등장 캐릭터)
- **김두한** — 노쇠한 노장 에이스. 전투력은 전성기보다 떨어졌지만(hp 중상·speed 중하·accuracy 중) 아군 규합 패시브와 후반 자폭형 일격기로 정체성 유지. 추천 방향=정치/연설 버프 + 단발 고화력. 핵심 스킬·패시브 모티프: "역사의 회상" 각성 버프, "똥통 투척" 자폭 굴욕기, "굴복 거부" 고문 저항.
- **이찬오** — 고려대생 출신 보좌관. 민첩한 서포터/디버퍼(speed 높음·hp 낮음·accuracy 높음). "부정선거 감시"로 적 정당성을 깎고, 두한의 재기를 트리거. 모티프: 정당성 디버프, 두한 각성 보조.
- **유지광** — 충성형 탱커(hp 최상·evasion 낮음·열0 고정 지향). 인접 아군 대신 피해를 떠안는 "오야붕 보호 진술" 도발/리다이렉트, 배신자 상대 분노 보너스. *주의: 2층 혁명재판 결단에 따라 영구 합류/이탈이 갈린다.*
- **시라소니** — 신앙형 서포터(speed 중·healer). 판정 유리화("위증/맹세")로 아군 명중·회피 버프, 후반 "전도"로 자기 디버프 정화. 모티프: 판정 조작 cleanse 계열.
- **조일환** — 봉양형 후계자(hp 중·균형형). 보급 heal/shield로 두한을 유지, 3층 이후 합류. 모티프: 후계 계승(두한 사망/이탈 시 일부 능력 인계 — *신규 프리미티브 필요, 아래 명시*).
- **(선택 합류) 이화룡** — 동류 협객 객원 딜러. event 노드 보상으로 영입 가능. 균형형 근접 딜러.

## 맵 구성 (노드 흐름)

### 1층 — 부정선거와 4.19
- **start → combat: 천일백화점 골목 습격** — 반공청년단 주먹(돼지·고바우) vs 고려대생/시위대. 적 로스터: 돼지(열0 탱커형 잡몹), 고바우(열0 근접 딜러), 반공청년단원 ×2(열1 군중). 의도=정통 다수 잡몹 전투, "학생 보호" 버프 학습.
- **combat: 마산 시위 진압** — 무차별 발포 분위기. 경찰 ×3(열0~1, accuracy 낮으나 area row 광역), 곽영주 부하 지휘관(열2 버퍼). 난이도=중. 광역 피해 관리 학습.
- **event(분기): 유지광의 명령 — "학생 손대지 말라"** — 선택지: ① 명령 거부(학생 보호) → 유지광 호감/2층 보호 진술 성공 확률↑, 보상 적음 ② 명령 수행(고대생 습격) → 즉시 gold/장비 보상, 단 2층 혁명재판에서 유지광 이탈 페널티. *분기는 패시브 플래그로 2층에 영향.*
- **elite: 경무대 발포 라인** — 곽영주(발포 지휘 엘리트) + 경찰 사수 ×3. 곽영주 패시브 "발포 명령"(라운드마다 area all 약공+fear 부여). 시위대 진격 컨셉=버티며 사수 먼저 정리. → clear.

### 2층 — 하야와 혁명재판
- **rest: 과도정부 — 잠시의 평화** — 회복 + 다음 청산 전 정비.
- **elite: 일제 검거** — 도주하는 동대문파 잔당. 빠른 적(speed 높은 evasion 딜러) 다수, 추격전 감각. accuracy 압박.
- **boss(비전투 결단): 혁명재판** — *전투 아닌 다단계 심판 노드.* 이정재·임화수·유지광의 "진술"이 판결(생사)을 가른다. 플레이어는 증언 선택을 통해 누구를 살릴지 결정:
  - 시라소니 위증 카드(아군 판정 유리) 사용 여부, 유지광 "오야붕 보호 진술" 발동 여부에 따라 분기.
  - 결과: 유지광 감형(무기→영구 합류) or 처형(이탈), 이정재 처형(고정, 두한 "유언" 디버프 정화 트리거). 임화수는 항상 자멸.
  - *구현: 비전투 event 체인 + 패시브 플래그. 새 메커니즘 아님(event 선택지 + grantStatus + 캐릭터 합류/이탈로 표현).* → clear.

### 3층 — 방황과 재기
- **event(도박): 애국단 창설** — 김종필의 권유. ① 수락 → 단원 2만(즉시 대량 gold/병력 보상) but "꼭두각시" 디버프(다음 층 시작 시 해산=보상 일부 회수, 정당성 하락) ② 거부 → 보상 없으나 이찬오 신뢰 +, 재기 버프 확정. 도박형 고위험 노드.
- **classChange: 한독당 재건 (두한 전직)** — 두한 직업 트리 분기. "정치인 김두한"(연설/규합 강화 패시브 + 전용 유세 스킬) vs "독립군 김두한"(자폭 일격 강화 + 돌격 스킬). 인원 캡 내 전직.
- **event: 용산의 회상 (김무옥)** — 죽은 동지의 기억. 비전투 데코 → 두한 "역사의 회상" 각성 버프 영구 부여(might+edge).
- **combat: 거리 유세 방해 세력** — 우미관패 vs 선거 방해 깡패. 정통 전투, 재기 버프 체감. → clear.

### 4층 — 최후
- **boss(버티기): 중앙정보부 고문실** — 김형욱 + 이과장. *적을 죽이는 게 목표가 아님.* 매 라운드 전기/물 고문(강력 DoT+paralyze+fear)을 거는 적에게 **두한이 "굴복 거부 버티기"로 N라운드 생존**하면 승리(국회 석방 결의안 가결 연출). 저항 게이지=두한 hp 유지. 패배=굴복 엔딩.
- **event: 사카린 밀수 폭로** — 똥통 준비(파고다공원 인분 수집) 셋업 데코.
- **boss(연출 클라이맥스): 국회 본회의 똥통 투척** — 사카린 밀수 내각(국무위원 ×4, 고hp 무저항 표적)을 향한 일격. 두한 "똥통 투척" 자폭 굴욕기 = area all 대굴욕 데미지 + 자기 평판/안전 대가(구속 디버프). 사실상 처치 불가능한 적에게 한 방 먹이고 끝나는 **승리이자 파멸**.
- **데코(엔딩): 참회와 죽음** — 절에서 "너무 많은 사람을 죽였습니다" 참회 기도 → "참회/자기 성찰"로 전 디버프 정화. 1972.11.21 사망 텍스트. 최동열 회고로 런(과 드라마) 종결. → clear.

## 적 캐릭터 (로스터)
- **돼지 / 고바우** — 반공청년단 주먹. 열0 근접 잡몹. 단순 damage AI, hp 낮음. 1층 도입 적.
- **경찰 사수** — 자유당 진압 경찰. area row 광역 사격, accuracy 낮음(무차별 발포). AI=무작위 광역 우선.
- **곽영주** — 경무대 경호실장(엘리트). 패시브 "발포 명령"(when=turnStart, then=area all 약공+applyStatus fear). 처형 시 "대한민국 만세" 자폭 연출(death 트리거 광역 한방). AI=공격적, 다수 타겟 선호.
- **임화수** — 비열한 책략형(혁명재판 NPC). "죄 전가"=아군에게 디버프 떠넘기기 시도, 단 자멸 리스크(본인도 사형 고정). 비전투 결단의 배신자 축.
- **김형욱** — 중정부장(고문 보스). 패시브 고문(when=turnStart, then=강력 DoT bleed/burn + paralyze + fear). "빨갱이 규정"으로 두한 약화. AI=두한 단일 집중.
- **이과장** — 중정 수사관(고문 보조). 김형욱 보조 디버퍼. paralyze/weaken 부여.
- **국무위원 ×4** — 사카린 밀수 내각(연출 보스 표적). 고hp·무저항(거의 공격 안 함), 두한 굴욕기의 과녁. AI=수동.
- **(2층 잡몹) 동대문파 잔당** — speed 높은 evasion 딜러. 추격전 압박.

## 설계할 스킬·패시브 (이 런 신규 콘텐츠 후보)
모두 기존 프리미티브 조합 = **[데이터-온리]** (예외는 별도 명시).

- **학생 보호** (두한/유지광 패시브) — when=battleStart, if=아군 중 "학생/시위대" 태그 존재, then=applyStatusSelf shield + 아군 ally area 방어 buff. *데이터-온리.*
- **사전투표 조작** (임화수/적 디버프 스킬) — target=enemy, applyStatus weaken(정당성 깎기 표현). *데이터-온리.*
- **발포 명령** (곽영주 패시브) — when=turnStart, then=area all damage(약) + applyStatus fear. 역풍은 "이후 시위대 분노" 연출로 처리. *데이터-온리.*
- **굴복 거부 버티기** (두한 스킬/패시브) — applyStatusSelf invincible/undying류 단기 + cleanse(고문 DoT 일부 정화). when=damaged, if=hpPct 낮음, then=undying 1턴. *데이터-온리.*
- **똥통 투척** (두한 전용 일격기) — target=enemy, area all, damage(대) + applyStatusSelf "구속" weaken(자기 대가). cooldown 길고 alwaysHit. 자폭 굴욕기. *데이터-온리.*
- **오야붕 보호 진술** (유지광 스킬) — target=ally(인접 오야붕), taunt 자신에게 집중 + 대상 shield. 배신자(임화수 태그) 상대 시 might 자가 보너스. *데이터-온리.*
- **위증/맹세** (시라소니 스킬) — target=ally, applyStatus(명중/회피 buff) + cleanse. "판정 유리화". *데이터-온리.*
- **전도** (시라소니 후반 스킬) — target=ally area, cleanse(디버프 정화) + 소량 heal. *데이터-온리.*
- **역사의 회상 (김무옥)** (두한 각성 버프) — event로 부여되는 영구 applyStatusSelf might + edge. *데이터-온리(event grantStatus).*
- **참회/자기 성찰** (두한 엔딩 스킬) — applyStatusSelf cleanse(전 디버프 정화) + heal. 최종 각성 트리거. *데이터-온리.*
- **부정선거 감시** (이찬오) — target=enemy, applyStatus weaken(정당성↓) + accuracy 디버프. *데이터-온리.*

## 전직·특수 메커니즘 (해당 시)
- **두한 전직 (classChange, 한독당 재건)**: 차수별 분기.
  - *정치인 김두한* — 패시브 "연설/규합"(when=turnStart, then=ally area 소량 might·regen), 전용 스킬 "거리 유세"(아군 광역 buff).
  - *독립군 김두한* — 패시브 "아버지의 총탄"(when=onHit, if=hpPct 낮음, then=damage 보너스), 전용 스킬 "돌격"(self might + reach 증가 단일 고화력). "똥통 투척" 강화 해금.
- **혁명재판 (비전투 결단 보스)**: event 체인 + 패시브 플래그로 동료 생사 분기. 1층 "학생 손대지 말라" 선택과 시라소니 위증 사용 여부가 유지광 합류/이탈 결정. *기존 프리미티브로 구현 가능(event 선택지 + grantStatus + 캐릭터 합류/이탈).*
- **고문 버티기 보스 (승리 조건 = N라운드 생존)**: "적 전멸"이 아니라 "지정 라운드 버티기"가 승리. → **신규 프리미티브 필요 가능성**: 현재 boss 노드는 적 roster 전멸이 기본 승리 조건. *"생존 라운드 도달 시 승리(survival-victory)" 승리조건이 엔진에 없다면 프리미티브 갭.* 대안: 김형욱·이과장에게 매우 높은 evasion+고정 hp 부여 후 "라운드 한계 도달 = 강제 후퇴(승리 이벤트)"를 round 트리거 패시브로 표현하면 **데이터-온리로 근사 가능**. 정식 survival 승리조건은 별도 승인 후 추가 권장.
- **후계 계승 (조일환)**: 두한 사망/이탈 시 일부 스킬·능력을 조일환에게 인계. → **신규 프리미티브 필요**: 현재 캐릭터 간 능력 인계(ability-transfer-on-death) 메커니즘 없음. 이 런 필수는 아니므로 **연출(데코 텍스트 + 조일환 강화 버프 grantStatus)로 대체 가능**. 정식 인계 메커니즘은 향후 승인 시 추가.

## 난이도·길이·보상 흐름
- **길이**: 4층, 노드 약 14~16개(전투 6~7, 엘리트 2, 보스 3, event/도박 3~4, rest 1, classChange 1, 엔딩 데코 1). 야인시대 런 중 **최장·최종**.
- **난이도 곡선**: 1층=정통 전투 학습(중하) → 2층=청산·결단(중, 비전투 압박) → 3층=도박/회복(변동) → 4층=고문 버티기(상, 인내) + 연출 클라이맥스(낮은 전투 난이도·높은 정서).
- **보상**: 1~3층은 누적 성장(gold·스킬·이화룡 영입·재기 버프)이지만 **2층 혁명재판에서 동료 영구 이탈 리스크**가 병존 — "이기면서 잃는" 보상 철학. 4층은 새 보상보다 정서적 종결(똥통 투척 굴욕기 해금·참회 정화).
- **수치 방향(샘플)**: 두한 hp 높음(노장이라 speed 중하·accuracy 중), 똥통 투척 = area all damage 평타 ×3~4 + 자기 weaken 2턴 + cooldown 5. 곽영주 발포 = 매턴 area all 평타 ×0.5 + fear 1스택. 김형욱 고문 = 매턴 bleed 3스택 + paralyze 1턴(두한 단일). 고문 버티기 승리 = 5라운드 생존. 유지광 도발 = taunt 2턴 + 대상 shield(자기 hp의 30%).
- **엔딩**: 마지막 데코 노드는 전투 없이 참회→사망 텍스트로 마무리, "야인시대라고나 할까" 회고로 런(드라마) 전체를 닫는다.
