# 런 4: 해방과 좌우 대결 (원작 51~76화)

## 컨셉 (이 아크 → 런)

'주먹의 시대'가 '총·폭탄·이념의 시대'로 넘어가는 전환 런. 김두한이 좌익 전위대장에서 우익 반공 행동대장으로 **전향**하는 정체성 서사가 런의 척추다. 앞선 런들이 1대1 협객 결투 중심이었다면, 런 4는 거점 공략(다이너마이트·전선 절단·트럭 돌파)과 다수전·암살전이 일상화된다. 3개 층으로 구성한다.

- **1층 — 점령과 전향 (51~55화).** 무관부 무혈 점령으로 시작해, 아버지 김좌진 암살의 진실을 알고 전위대를 떠나 우익으로 돌아서는 층. 정체성 분기(전위대 잔류 유혹 → 전향) 이벤트가 핵심. 적은 일제 잔존·좌익 죄수 위주로 비교적 가볍다.
- **2층 — 좌우 무력 전쟁 (55~69화).** 아편 탈취·국군준비대 궤멸·암살 응수·금강 옥상 결투까지 런의 본체. 거점 파괴 노드, 1대다 시라소니 역방향 엘리트, 금강 페이즈 보스가 몰린다. 가장 길고 험하다.
- **3층 — 우정의 파국 (70~76화).** 애국헌금 자원전, 좌우합작 방해, 개코 자결, 김일성 암살 잠입(실패 보상), 최종 보스 정진영(빈총 기믹). 도덕적 비용이 보상에 얹히는 층.

플레이 경험: 매 층 "이기는 방식이 곧 잃는 것"이라는 비극을 자원·선택지로 체감시킨다. 전향서·자결·빈총처럼 **처치하지 않고 무력화/이탈**시키는 선택이 보상·후환과 맞물린다.

## 플레이어 파티 (등장 캐릭터)

- **김두한** — 전향형 주인공/리더. 폭발물+권총+맨손 복합 딜러. 추천 방향: 균형형(중 HP·중 SPD·고 accuracy), critChance 약간. 핵심 패시브 **아버지의 환영**(HP 임계 이하 1회 부활+대반격), 핵심 스킬 **다이너마이트 기습**(square area damage). 전향서/처형 선택지로 적을 이탈시키는 메커닉의 주체.
- **시라소니(이성순)** — 압도적 단독 무력. 2층 형제 결의 이벤트 클리어 시 합류. 고 HP·고 evasion·근접 reach 딜러. 패시브 **만취 광폭**(약화/취함 상태일수록 공격력↑, 다수 상대 보너스). 합류 전엔 1대다 엘리트 노드의 아군 NPC.
- **신영균** — 폭파·방화 전문 행동대장. 저 HP·중 SPD·고 accuracy. 거점 노드 특화(전선 절단·창고 폭파 area 스킬), 1대1 결투 가능. col/row area 딜러.
- **김무옥** — 두한 직속 돌격 부하. 고 HP 전열 탱커/그래플러. 납치(이동 제압)·도발 보유. 2층 용산 파업 노드에서 **전사 이벤트**(서사상 영구 이탈) — 캠페인이면 그 전까지 운용.
- **개코** — 비전투 중재자/지원형. 저 HP·고 SPD. heal/cleanse/사기 부여 위주, 직접 딜 거의 없음. 화해 이벤트 트리거 캐릭터. 3층 자결 이벤트로 이탈.
- **김영태 / 문영철 / 상하이조** — 우미관패 일반 대원 풀(전열 난타·권총 사격). 진형 채움용 서브 딜러로 1~2명 동행.

## 맵 구성 (노드 흐름)

```
start
  └─[1층] combat(무관부) → event(전위대장 취임 vs 전향 도화선) → combat(유치장 좌익 죄수)
            → classChange(전향: 전위대장→우익 별동대장) → boss?(없음, 1층은 전향 이벤트가 분기 핵) → clear
  └─[2층] combat(전매국 아편 경비) → shop(사고야마 정보상) → elite(이화룡 명동 첫충돌)
            → event(시라소니 자진무릎: 형제결의/결투 분기) → combat(태릉 국군준비대 거점)
            → rest(애기보살 은신처) → elite(중앙극장 심영 추격) → event(애기보살 집 포위 피격)
            → boss(금강 옥상 결투, 페이즈제) → clear
  └─[3층] event(애국헌금 강제징수: 의적/강도 분기) → combat(용산 파업 진압)
            → event(좌우합작 방해: 김규식/여운형) → elite(김해숙 배신 총격전)
            → event(개코 자결 도덕 선택) → combat(김일성 별장 잠입: 실패해도 보상)
            → boss(정진영 최종전, 빈총 기믹) → clear(미군 체포 → 사형 통보 엔딩)
```

- **1층 combat — 무관부 점령** (우미관패 vs 해군무관부 잔존병): 트럭 돌파/다이너마이트로 정문 파괴 = 첫 턴 거점 area 딜 보너스. 적은 소총수 3~4 + 장교 1, 방어형 진형. 튜토리얼급.
- **1층 event — 전위대장 취임**: "독립군 사령관" 제안 수락(좌익 보상 일시) vs 박용직 폭로로 전향(영구 노선 확정). 분기로 1층 클리어 경로가 갈림.
- **1층 combat — 유치장**: 좌익 죄수 다수전. 맨손 전용 제약 노드(무기 압수 디버프).
- **1층 classChange — 전향**: 두한이 좌익 스킬 트리 → 우익 별동대장 트리로 전직. 인원 캡 +1.
- **2층 combat — 전매국 아편 탈취**: 야간 기습. 창고 경비 + 일본 야쿠자 잔당. 전선 절단(신영균)으로 적 지원(증원) 차단 기믹.
- **2층 shop — 사고야마 정보상**: gold로 아편 정보·무기 구매. 협상 이벤트 끼움.
- **2층 elite — 이화룡 명동 충돌**: 이화룡 + 명동파 정팔·황병관. 강화 전투, 호각의 라이벌전.
- **2층 event — 시라소니 자진무릎**: 시라소니와 결투(고위험 엘리트) vs 자진 무릎(전투 회피+형제 결의 = 합류). "지는 게 이기는 것".
- **2층 combat — 태릉 국군준비대 거점**: 대규모 거점 파괴. 무기고/탄약창 폭파 = 라운드 한정 폭발 area. 정진영 부하 정진영 휘하 대원 다수.
- **2층 rest — 애기보살 은신처**: 회복. heal + 디버프 cleanse.
- **2층 elite — 중앙극장 심영 추격**: 심영 + 좌익 배우/경호. 처치 직전 노모 애원 = **전향서 분기**(처치 안 하면 후환↓, 처치하면 보상↑).
- **2층 event — 애기보살 집 포위**: 정진영 기습 총격, 두한 피격. 생존 판정 후 미군병원 인수(아버지 환영 패시브 각성 보상).
- **2층 boss — 금강 옥상 결투**: 거구 탱커. 페이즈제(아래 보스 섹션).
- **3층 event — 애국헌금**: 부호 30여 명에게 강제 징수. 이승만 휘호=위협 보너스, 영수증 발행=의적 노선(후환↓ 자금↓) vs 강탈=강도 노선(자금↑ 민심 디버프).
- **3층 combat — 용산 파업 진압**: 전평 노조 다수. 허성탁의 약속 위반 총격 = 김무옥 전사 스크립트 이벤트.
- **3층 event — 좌우합작 방해**: 김규식 협박/여운형 납치(비전투 위협전). 정치 자원 보상.
- **3층 elite — 김해숙 배신 총격전**: 김천호 공작으로 김해숙 사망. 방직공장 정면 충돌, 정진영 직속 정예.
- **3층 event — 개코 자결**: 여공 사망 누명. 명예를 위해 자결 명령(개코 영구 이탈, 별동대 결속 버프) vs 거부(개코 잔류, 조직 규율 디버프). 가장 무거운 선택.
- **3층 combat — 김일성 별장 잠입**: 잠입형. 성공/실패 무관 보상(서사상 실패 확정이나 게임은 부분 보상). 백관옥·박용직 동행.
- **3층 boss — 정진영 최종전**: 빈총 기믹 보스(아래).
- **clear — 사형 통보 엔딩**: 미군 체포 컷신. 런 클리어, 다음 런(5장)으로.

## 적 캐릭터 (로스터)

- **정진영** (최종 보스/좌익 전위대장) — 이념 광신. 부하 소환(김천호·김해숙)·약화/공포 디버프 분배. AI: 두한 집중 타겟, 부하 살아있을 때 방어적·전부 죽으면 공세 전환. 화해 이벤트 분기 보유(비극형).
- **금강 ('북경의 곰')** (2층 보스) — 거구 탱커. 고 HP·고 critMultiplier 단타, 저 SPD. 날라차기 강타 + 지형 활용 **밀어 추락**(move로 적을 전열 밖으로 밀어 추가 피해). 패배 후 존중·이탈(처치 아님). AI: 단일 최강타 위주.
- **이화룡** (2층 엘리트, 명동파 두목) — 두한의 호각 라이벌. 균형형. 명동파 진형 버프 부여. AI: 진형 유지·반격형.
- **김천호** (좌익 암살자) — 차량 폭탄/기습 딜러. 저 HP·고 SPD·고 critChance, 저 accuracy(빗나가면 큰 손해). 매복(첫 턴 은신→기습). AI: 두한 후열 저격.
- **김해숙** (좌익 정예) — 정진영 연인·정예 대원. 중 HP, 권총 사격 + regen. 배신 이벤트에서 적→피해자로 전환.
- **신불출** (좌익 참모장) — 비전투형 디버프 지휘관. 적 사기 부여·아군 약화. 납치 이벤트로 무력화 가능(전투 회피).
- **심영** (좌익 배우) — 중앙극장 엘리트. 저 HP 회피형, 도주 패시브(HP 임계 시 전장 이탈). 전향서로 무력화 가능.
- **허성탁** (좌익 무력 간부) — 약속 위반·총격 명령. 함정형(휴전 깨고 기습). 용산 노드 스크립트.
- **국군준비대/전평 노조 잡병** — 거점 노드 다수전. 소총수·노조원·죄수. 진형 채움, 증원 웨이브.
- **워태커 / 미군정** (엔딩 NPC) — 비전투. 사형 통보 컷신. 시간제한·체포 위협 디버프의 서사적 출처.

## 설계할 스킬·패시브 (이 런 신규 콘텐츠 후보)

원작 싸움 방식 → 프리미티브 매핑. (대부분 **데이터-온리** 조합으로 표현 가능. 신규 프리미티브 필요분만 명시.)

- **다이너마이트 기습** (두한): damage, area=square, cooldown 높음, 고위력. 거점 노드 첫 턴 정문 파괴 보너스.
- **연막·수류탄 투척**: damage(약) + applyStatus(weaken or 명중저하), area=cross. 광역 견제.
- **전선/전화선 절단** (신영균): applyStatus(적 지원차단). → **데이터로 표현:** 적 증원 트리거를 weaken 유사 "지원불가" 상태로 모델. 새 상태이상 **`isolate`(지원/소환 차단)** 가 깔끔하면 **신규 프리미티브 필요(상태이상)**. 없이 가려면 적 소환 스킬에 "아군 isolate 보유 시 무효" if-조건 → 이건 패시브 if로 가능하므로 **데이터-온리로 수렴 가능**.
- **창고 폭파** (신영균): damage, area=row 또는 all(거점 한정), 자가 cooldown 큼. 라운드 한정 환경 폭발.
- **트럭 돌파**: move(아군/자기 전열 진입) + damage(돌파 대상). 첫 턴 진입 버스트.
- **아버지의 환영** (두한 전용 패시브): when=damaged, if=hpPct≤임계 & 미발동, then=heal(부활) + applyStatusSelf(might 대반격) + grantsInterrupt. 1회 한정. → 기존 특성 트리거+effect 조합으로 **데이터-온리** (1회 제한 플래그는 if=미발동 조건으로).
- **만취 광폭** (시라소니 패시브): when=turnStart, if=hasStatus(weaken/취함), then=applyStatusSelf(might). 다수 상대 보너스는 적 수 비례 → **적 수 조건이 if에 없으면 신규 프리미티브 필요(if 조건: enemyCount)**. 없이 가려면 area=all 광역 스킬 + might 스택으로 근사 = **데이터-온리 근사 가능**.
- **자진 무릎(외교 회피)**: 전투 노드가 아닌 **event 노드 선택지**로 구현(전투 스킬 아님). 결투 회피 + 캐릭터 합류. 프리미티브 불요(event 분기).
- **전향서/처형 선택**: elite 노드 클리어 후 event 분기 — 적 처치(보상↑) vs 무력화 이탈(후환↓). event 노드로 표현, 프리미티브 불요.
- **박치기/그래플 카운터** (김무옥): when=damaged(근접), then=damage 반격(reflectByDamage 유사). 기존 반사 패시브로 **데이터-온리**.
- **매복 저격** (김천호): 첫 라운드 은신 → 기습. → **은신(첫 턴 타겟불가) 상태**가 없으면 **신규 프리미티브 필요(상태이상 stealth)**. 근사: round1 high evasion + 첫 턴 alwaysHit 스킬로 대체 = **데이터-온리 근사**.
- **밀어 추락** (금강): move(적 deltaCol 강제) + 추가 damage(전열 밖 밀림 시). 기존 move + if(위치) 조합 = **데이터-온리**.
- **애국헌금/좌우합작 협박**: event 노드 자원 변동. 휘호=위협 성공률 보정, 영수증/강탈=후환 분기. 프리미티브 불요.
- **빈총 기믹**: 최종 보스 페이즈 연출 — event/스크립트. 전투 메커니즘 아님.

> **신규 프리미티브 후보 종합**(승인 필요 시 보고): ① 상태이상 `isolate`(지원/소환 차단) ② 상태이상 `stealth`(첫 턴 타겟불가) ③ if 조건 `enemyCount`(다수전 비례 버프). 셋 다 **데이터-온리 근사로 우회 가능**하므로, 충실도 우선이면 추가 제안, 아니면 근사 채택. 나머지는 전부 기존 프리미티브 조합 = **[데이터-온리]**.

## 전직·특수 메커니즘

- **두한 전향 (classChange, 1층)** — 좌익 전위대장 트리 → 우익 별동대장 트리. 전향 시 좌익 전용 스킬 봉인, 우익 전용 스킬(다이너마이트 기습·애국헌금 권한·처형/전향서) 해금 + 패시브 '아버지의 환영' 부여. 분기는 패시브로 차별(전향 거부 잔류 = 좌익 버프 유지하나 후속 우익 노드 봉쇄 → 사실상 캠페인 정사 경로는 전향).
- **거점 파괴 모디파이어** (combat 변형) — 전매국·태릉·전평 본부 노드는 "구조물 HP"를 별도 타겟으로 두고 area 폭파 스킬로 추가 보상(자금·전력 복구). 구조물 = HP만 있는 더미 적 유닛으로 모델 = **데이터-온리**.
- **잠입 노드** (김일성 별장) — 실패 확정 서사 → 게임은 "도달 라운드 비례 부분 보상" combat. 전멸 페널티 완화.
- **시라소니 합류 게이트** — 2층 자진무릎 이벤트 성공 시에만 파티 합류(인원 캡 내). 결투 선택 시 미합류·고난도 보상.

## 난이도·길이·보상 흐름

- **길이**: 3개 층, 층당 7~9 노드 (총 24~27). 런 4는 캠페인 중반 난이도 봉우리(거점·암살·페이즈 보스 밀집).
- **난이도 곡선**: 1층 완만(전향 서사·튜토리얼급 다수전) → 2층 급상승(거점 파괴 기믹 학습 + 1대다 시라소니 엘리트 + 금강 페이즈 보스) → 3층 고지대(도덕 선택이 영구 디버프/이탈을 부과, 최종 정진영전).
- **금강 보스 (2층)**: 2페이즈. P1 = 금강 풀체력 압박(밀어 추락으로 두한 후열 강제). HP 임계 시 두한 "위기" → **아버지 환영** 발동 = P2 might 대반격. 처치 시 금강 이탈(존중)·고급 보상.
- **정진영 보스 (3층, 최종)**: 부하(김천호·김해숙) 동시 등장 → 부하 처치할수록 정진영 공세 강화(분노 스택). 막판 빈총 event 연출 → 확정 처치. 비극 엔딩 컷신.
- **보상 흐름**: 1층=전직·스킬 해금 중심(자금 적음). 2층=거점 자금 대량(아편·헌금 전초)·시라소니/스킬 강화. 3층=애국헌금 대량 자금 but 노선 따라 민심/결속 패시브 분기 → 다음 런 메타에 전이. 처형/전향서·개코 자결 선택은 **즉시 보상 vs 영구 비용** 트레이드오프로 비극 테마를 수치화.
- **데이터/엔진 분류**: 본 런은 **[데이터-온리]** 가 기본. 충실도 상향 옵션(`isolate`/`stealth`/`enemyCount`)만 **[엔진 프리미티브 추가]** 후보로 사전 승인 대상. 거점 구조물·환영 부활·밀어 추락·반격은 전부 기존 프리미티브 조합으로 구현.
