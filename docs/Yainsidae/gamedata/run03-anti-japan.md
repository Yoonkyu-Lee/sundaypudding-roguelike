# 런 3: 일제말 항일 — 혼마찌 대결 (원작 30~50화)

## 컨셉 (이 아크 → 런)

런 1·2가 "조선 주먹들 간의 종로 패권 다툼"이었다면, 런 3은 **상대가 민족(일본)으로 바뀐다.** 적은 더 이상 같은 종로 골목의 깡패가 아니라 **혼마찌 야쿠자(진검)·일본 경찰(유도 명인)·헌병대(고문)·총독부(제도 폭력)** 다. 핵심 플레이 경험은 "무력 대 제도"의 비대칭이다 — 칼·주먹으로 못 이기는 적(미와·헌병대)이 나타나고, 플레이어는 **전투 외 자원(명예·민족·의지)** 으로 그들에게 맞서야 한다.

3개 층 구조:

- **1층 — 혼마찌 전면전 (30~40화).** 정통 무력 충돌. 야쿠자 결투(시바루·가미소리), 경찰 결투(마루오까), 진검 사무라이 레이드(장충단). 핵심 보스 = 마루오까(약점=턱)·하야시(소환사 메타 보스). 명예 코드 메커니즘(자진 중단·의형제)의 무대.
- **2층 — 헌병대 고문 (41~44화).** **전투력으로 못 이기는 층.** 미와·헌병대는 HP 깎기가 아니라 **의지(고문 항거) 자원 싸움.** 번개의 죽음·설향의 희생이 이벤트로 박힌다. 1대3 무술 시합(연속전)이 보스.
- **3층 — 징용·해방 (44~50화).** 전국 주먹패 연대(파티 확장), 근로보국대 자괴감, 부민관 의거(일회성 광역 폭탄 이벤트), 그리고 **해방 = 미와의 자결(특수 종료).** 보스가 "이기는" 게 아니라 "버티면 시대가 끝난다"는 역전 카타르시스.

전체 정체성: **두한이 건달에서 "무산대중의 영웅"으로 각성하는 런.** 승리가 곧 카타르시스가 아니라, 상실(박인애·설향·번개) 위에 정체성이 쌓이는 무거운 톤.

## 플레이어 파티 (등장 캐릭터)

- **김두한 (주인공·1대다 영웅형)** — 조선식 주먹·발차기. 1대다수에서 강해지는 "각성" 패시브가 정체성. 핵심 스킬 모티프: 날아 차기(턱 약점 특효·기절), 풍차 돌려차기(`area:cross` 광역). 추천 스탯: HP 높음·accuracy 중·critChance 높음(약점 피니셔). 열0(최전열) 고정형.
- **김영태 (참모·지원/버프형)** — 비전투에 가까운 2인자. 구명운동·전략. 모티프: 아군 의지/명예 버프 부여(`applyStatus` ally), 고문 항거 패시브 보유. 추천: HP 중·speed 낮음·전투 기여 낮고 유틸 높음. 후열(열2~3).
- **김무옥 (정찰·약점 노출형)** — 적 도장 잠입으로 보스 약점을 사전 공개. 모티프: `applyStatus` 적 weaken/pierce(약점 노출) + 전투 전 정보. 추천: evasion 높음·accuracy 높음·HP 낮음. 측면(열1).
- **정진영 (신념·중열 딜러)** — 신불출에게 사회주의 사상을 전수받는 캐릭터. 모티프: 각성 시 might 자버프, 신념 스택형. 추천: 균형형. 열1~2.
- **문영철 (정통 격투·근접 탱커)** — 마루오까와 조건부 결투(패배)·신영균과 화해 결투. 모티프: 도발(`taunt`)·반격(반사 패시브). 추천: HP 높음·evasion 낮음·정면 받이. 열0.
- **번개 (속공·비극)** — 빠른 잡졸 정리형. **2층에서 헌병 고문으로 사망(서사적 상실).** 모티프: 고속 다단 타격(speed 높음·낮은 단타). 추천: speedMax 매우 높음·HP 낮음. 2층 진입 후 특정 이벤트로 영구 이탈.
- **개코·삼수 (잡병 처리·수적 우세)** — 머릿수형 동료. 단독으론 약하나 진형 열보너스로 합산 기여. 추천: 평범, 후열 채움.
- **설향 (비전투 지원·구명)** — 협상/희생. 전투 캐릭이 아니라 **2층 구명 이벤트의 트리거**(다이호 유인 → 두한 석방 + 무술 시합 개시). 모티프: 아군 부활/석방 이벤트 노드. 새벽에 떠나며 영구 이탈.
- **신불출 (사상 전파·각성 지원)** — 비전투. "무산대중의 영웅" 호명 = 두한·정진영에게 영구 패시브(각성) 부여하는 이벤트성 지원 캐릭터.

- **event:아편소각** — 데코/선택지. 아편 소각=민족 자원 +, 협상 수락=gold +지만 명예 −. 적대 선언으로 1층 확정.
- **combat:아사히마찌 기습** — 다나까 부하 다수. 잡졸 위주, 워밍업. 두한 1대다 패시브 체험.
- **elite:시바루 결투** — 1:1 무도인. 두한이 우위에서 자진 중단 → **명예 자원 + 아군 버프**(자진 중단의 도량). 죽이면 보상 적고, 살려주면 명예↑.
- **boss:마루오까(1층 보스)** — 유도 명인. 진형보너스 ON. **약점=턱**: 김무옥 정찰(`pierce`/약점 노출) 후 두한 날아 차기로 크리. 패배시키면 이후 **의형제 전직 이벤트**로 아군 합류 가능.
- **boss:장충단 레이드(2국면)** — 1국면=주먹 야쿠자 다수(1대다, 두한 단독), 2국면=가미소리+진검 사무라이(`bleed` 다발). 중간에 5인방 합류(동료 복귀). 고노에 중단 명령 → 하야시 "내가 졌다"(명예 패배 연출).
- **classChange:무산대중의영웅** — 신불출 각성. 두한 1차 전직(아래 전직 섹션).
- **boss:미와 고문 대결(2층 보스)** — **비표준 보스.** HP 깎기 아님. 미와가 매턴 `applyStatus`(fear/약화)로 의지 잠식, 두한은 "고문 항거" 자원으로 버틴다. 일정 라운드 버티면 클리어(설향 희생 이벤트가 보조).
- **elite:헌병 정예 3연전** — 요시모토·하세가와 등 연속 3전(회복 없음, 누적). 마지막 "죽을 수도 있다" 경고 = 강화 적.
- **event:전국 오야붕 회의** — **파티 확장 노드.** 작두·장도리·신영균·이정재를 일시/영구 동료로 영입(선택). 이정재는 합류하나 "라이벌 복선" 디버프 태그.
- **boss:해방(런 보스)** — 미와 전기 고문 N라운드 버티기 → 옥음방송 트리거 → 미와가 일장기 경례 후 권총 자결(특수 종료, 전투 승리 아님).

## 적 캐릭터 (로스터)

- **하야시 (혼마찌 오야붕·메타 보스/소환사)** — 직접 안 싸운다. 매턴 부하·경찰·헌병을 `castSkill`로 소환/강화. 명예 코드: 본대 전멸 시 항복(특수 패배, 적대→공존). AI: 자원 소모형, 본인 보호 우선.
- **마루오까 (경찰·유도 명인 보스)** — 엎어치기(`move` 강제 재배치)·조르기(`applyStatus` paralyze SPD−)·관절기. **약점=턱**: 특정 상태(pierce/약점노출) 부여 시 받는 피해 대폭↑. AI: 전열 그래플 우선.
- **가미소리 (진검 지휘관·암수)** — 기습/계략 특기. `applyStatus` bleed 다발, 전투 시작 시 아사히마찌 증원 소환. 패배 시 할복(특수 사망). AI: 약체 우선 타격.
- **시바루 (무도인 엘리트)** — 관절기·날라차기. **"비겁한 싸움 거부" 패시브**: 아군이 2명 이상으로 협공하면 참전 거부(빠짐) → 1:1 유도. AI: 명예형, 1:1 선호.
- **미와 (고등계·비전투 탄압 보스)** — 의지/정신 공격. damage 거의 없고 `applyStatus` fear(쉴드잠식)·weaken·정신 약화 도배. "고문 항거" 패시브로만 무효화. AI: 가장 의지 낮은 대상 집중.
- **다이호 대좌 / 스즈끼 대위 (헌병대)** — 전기·물 고문. 광역 DoT(`burn`/`bleed` `area:all`). 설향 이벤트 트리거 대상. AI: 광역 우선.
- **다나까 (아사히마찌 오야붕)** — 아편 밀매·증원 동원. 잡졸 소환형 미니보스. 마루오까에게 검거(이벤트 퇴장).
- **헌병 정예(요시모토·하세가와 등)** — 3연전 엘리트. 각자 다른 무술(타격/관절/조르기), 연속전이라 누적 피해 압박. AI: 정석 딜러.
- **일본 축구단/순사/보초** — 잡졸 다수. 머릿수로 두한 1대다 패시브 시험.

## 설계할 스킬·패시브 (이 런 신규 콘텐츠 후보)

원작 싸움 방식 → 프리미티브 매핑:

- **날아 차기 (피니셔)** — `damage` 단일 고배율 + `applyStatus freeze(기절)` 1턴. 대상이 약점노출/pierce 상태면 critMultiplier 추가 적용(데이터: critChance 보정 패시브). 두한 시그니처.
- **풍차 돌려차기** — `damage area:cross` 광역, 1대다용. 두한 각성 시 amount↑.
- **자진 중단의 도량 (패시브)** — when=`kill` 직전(if=대상 HP≤임계) then=처치 대신 `applyStatus self might`(명예 버프) + 아군 전체 `applyStatus regen`. **[엔진 프리미티브 필요?]** → "처치 대신 살려두기"는 기존에 없음. **신규 프리미티브 필요: `spare` 효과(킬 시점 대상 HP를 1로 고정 + 트리거 발화).** 기존 damage/heal로는 "죽이지 않고 멈춤"을 원자적으로 표현 불가.
- **1대다 각성 (패시브)** — when=`turnStart` if=(아군 생존수 < 적 생존수) then=`applyStatusSelf might + edge`. 동료가 적을수록 강해짐. 기존 프리미티브 조합으로 **데이터-온리** 가능(생존수 조건이 if에 있다면). **[조건 확인 필요]**: `if`에 "아군/적 생존수 비교"가 없다면 **신규 조건 필요**.
- **약점 정찰 (잠입, 김무옥)** — `applyStatus enemy pierce + weaken`(약점 노출). 전투 전 노드 이벤트로도 발화. 데이터-온리.
- **고문 항거 (의지, 패시브)** — when=`damaged`/`turnStart` if=(hasStatus fear/약화) then=`cleanse self` + 동료 정보 보호(미와 보스의 정보 누설 메커닉 무효). 정신 공격 무효화. 데이터-온리(cleanse + 확률).
- **무사도 인정 / 의형제 (회심)** — 보스 패배 후 아군 전환. **[엔진 프리미티브 필요?]** → 전투 중 적→아군 진영 전환은 기존에 없음. 단, **전투 후 classChange/event 노드에서 캐릭터를 파티에 추가**하면 데이터-온리로 충분(마루오까 합류). 전투 중 즉시 전향이 필요하면 **신규 프리미티브: `convert`(소속 전환).** → 이 런은 이벤트 합류로 처리 권장(데이터-온리).
- **계략/암수 (가미소리)** — `castSkill` 증원 소환(전투 시작 트리거) + bleed 다발. 데이터-온리(소환 = 적 추가 배치 트리거).
- **엎어치기 (마루오까)** — `move deltaCol`로 대상 강제 재배치(전열↔후열 흔들기) + 소량 damage. 데이터-온리.
- **할복/자결 (특수 사망)** — 명예 패배 연출. 전투 로직상 죽음이지만 `GameEvent` 특수 타입(할복)으로 연출 분기. **[엔진: 새 GameEvent 타입 추가]**(상태 변화 자체는 사망과 동일, 로그/애니만 분기) — 미와의 권총 자결도 동일.
- **부민관 의거 (사제 폭탄)** — 일회성 광역 이벤트 노드: `damage area:all` 초고배율 1회 + 이후 사용 불가. 데이터-온리(노드 효과).

## 전직·특수 메커니즘 (해당 시)

- **두한 전직 트리 (캐릭별 직업 트리):**
  - **1차 — "협객" (classChange:무산대중의영웅, 신불출 각성):** 패시브 부여 = "1대다 각성" 강화 + 명예 자원 획득량↑. 전용 스킬 보상 = 날아 차기 해금.
  - **2차 분기 — "민족 영웅" vs "건달 두목":**
    - *민족 영웅* — 민족 자원 소비형. 이벤트 거부(황국신민·창씨개명) 패시브 보너스, 의지 강화. 톤=각성.
    - *건달 두목* — 전투 화력 특화. might/edge 자버프, gold 효율. 톤=실리.
  - 분기는 **패시브로 차별**(같은 스킬풀, 패시브 세트가 다름).
- **마루오까 의형제 합류** — 1층 보스 격파 + 의형제 이벤트 선택 시 파티에 영입(인원 캡 내). 아군 마루오까 = 유도 탱커/그래플러.
- **미와 보스 = "의지전" 특수 룰** — HP 0이 아니라 **N라운드 버티기 클리어.** 미와 측 fear/약화 누적이 임계 도달 전 라운드를 넘기면 승리. 설향 희생 이벤트 = 즉시 클리어 트리거(대신 설향 영구 이탈).
- **해방(런 종료) = "버티기 + 시대 종료"** — 전투 승리가 아닌 라운드 생존. 옥음방송 트리거 후 미와 자결(특수 GameEvent)로 런 clear.
- **파티 확장(전국 연대)** — 2층clear 후 event 노드에서 작두·장도리·신영균·이정재 영입(인원 캡 내 선택). 이정재는 영입 시 "라이벌 복선" 태그(향후 런 빌드업, 이 런에선 패널티 없음).

## 난이도·길이·보상 흐름

- **길이:** 3층, 노드 ~26개. 표준 런(런1·2)보다 1.3배 길고 무겁게 — 1부 종결 아크의 위상.
- **난이도 곡선:**
  - 1층 = 정통 전투 난이도 상승(잡졸→엘리트→마루오까 약점 퍼즐→장충단 2국면 레이드). 무력으로 풀린다.
  - 2층 = **난이도 패러다임 전환.** DPS로 안 풀리는 미와(의지전)·헌병 광역 DoT(3연전 누적). "강해지기"가 아니라 "버티기/자원 관리"를 강제. **번개 영구 상실**로 전력 손실 + 정서적 압박.
  - 3층 = 파티 확장으로 전력 회복, 그러나 보스(해방)는 또 버티기. 부민관 의거 폭탄(일회성 광역)으로 숨통.
- **보상:**
  - 전투/엘리트 = gold + 스킬/특성. 1층 보스 = 마루오까 영입권 또는 강스킬.
  - **명예 자원**(자진 중단·의형제·도량) = shop 할인/특수 전직 해금 통화.
  - **민족 자원**(아편 소각·이벤트 거부·뱀 풀기·폭탄 지원) = "민족 영웅" 전직 분기 + 각성 패시브 강화.
  - **의지 자원**(고문 항거) = 2층 생존 통화. 부족하면 동료 정보 누설(추가 적 증원 페널티).
- **상실 = 코스트:** 박인애 이별(연애 이벤트 종료)·설향 희생(2층 즉시클리어 대가)·번개 사망(전력 −1). 보상과 상실이 교차하는 무거운 페이싱이 이 런의 톤.

### 엔진 프리미티브 갭 요약 (구현 전 승인 필요)
1. **`spare`(자진 중단의 도량)** — 킬 시점 대상 HP를 1로 고정 + 명예 트리거 발화. 기존 damage/heal로 "죽이지 않고 멈춤" 원자 표현 불가. **[엔진 프리미티브 추가]**
2. **"아군/적 생존수 비교" if 조건**(1대다 각성) — 기존 `if`에 생존수 비교가 없으면 신규 조건. 있으면 데이터-온리. **[확인 필요]**
3. **특수 사망 GameEvent**(할복/자결) — 상태변화는 기존 사망과 동일, 로그/애니 분기용 새 이벤트 타입. **[엔진: GameEvent 추가, 경량]**
4. **비표준 보스 종료 조건**(미와 의지전·해방 버티기) — "HP0" 대신 "N라운드 생존"이 보스 클리어 조건. 노드/보스 정의에 종료조건 필드가 없으면 신규. **[확인 필요]**

그 외(전직 분기·이벤트 합류·소환·move 재배치·약점노출·고문항거·부민관 폭탄)는 기존 프리미티브 조합으로 **데이터-온리** 가능.
