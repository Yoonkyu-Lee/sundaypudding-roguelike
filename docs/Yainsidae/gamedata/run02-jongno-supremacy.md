# 런 2: 종로 입성과 주먹 패권 (원작 9~29화)

## 컨셉 (이 아크 → 런)

무명 청년 두한이 종로 주먹계의 밑바닥에서 시작해, 일대일 결투(일기토)의 사다리를 올라 마침내 경성 최고 오야붕으로 등극하는 **"서열 등반 + 패권 통일"** 런이다. 핵심 정체성은 세 가지: (1) **맨손 vs 무기** — 두한 일행은 거의 맨손인데 야쿠자·우미관패는 일본도·손도끼·총까지 든다. 맨손 핸디캡을 콤보·그래플 탈출·각성으로 뒤집는 게 전투 손맛이다. (2) **민심(명분) 게이지** — 약자 보호·세금 감면으로 충전, 기습 피격·총기 대응으로 흔들리는 런 전역 자원. 세력 복속 확률·증원에 직결. (3) **일대일 결투 의례** — 잡졸 군집 전투(다대일 버티기)와 정식 1:1 보스 결투가 번갈아 나오는 리듬.

**3개 층(act) 구조:**
- **1층 — 입문과 합류 (9~15화):** 원노인 순국→복수 맹세→만주행 좌절→쌍칼 조직 입문. 첫 결투들(김무옥·문영철)과 신마찌 야쿠자 격전. 두한 혼자 또는 소수 파티. 난이도 입문.
- **2층 — 승계와 증명 (16~24화):** 쌍칼 vs 구마적(쌍칼 패배·후계 지목)→이정목 사수→두한 vs 신마적→혼마찌 진출→기습→**두한 vs 구마적 패권 결투(보스)**. 파티 확장(김영태·문영철·김무옥 합류). 난이도 중.
- **3층 — 통일과 새 적 (24~29화):** 작두→마포 용식→시구문 짝코 지역 복속 체인→**왕발(총기 보스)**→**다나까(아편 야쿠자 보스)**. 세력 복속 트리·외교·심리전. 난이도 상.

## 플레이어 파티 (등장 캐릭터)

- **김두한** (주인공·맨손 격투 에이스) — 발차기 콤보 마무리 + 박치기 그래플 탈출 카운터. 추천 스탯: hp 중상·accuracy 상·critChance 중·speed 중상. 핵심: 시그니처 패시브 **환영 부활**(HP 0 도달 시 1회 부활 + might 부여), 약자 보호로 민심 충전. 열0(최전열) 단독 돌격형.
- **정진영** (법학도·서포터/방패) — 전투력은 낮으나 의리로 두한을 감싸는 "몸빵 헌신"형. 추천: hp 중·evasion 하·나머지 하. 핵심: 아군 대신 피격(taunt·shield 부여) 패시브, 왕발전에서 두한 대신 총탄을 맞는 서사를 **반사/방패 발동**으로 재현.
- **개코** (거지패 왕초·소환/그래플) — 거지패 군집 동원 + "고간 잡기" 필살 그래플. 추천: hp 중·accuracy 중·critChance 상(그래플 한 방). 핵심: 군집 소환(임시 아군 토큰), 단일 고위력 그래플 스킬.
- **김영태** (참모·버프 서포터) — 휘문고보 책사. 비전투에 가깝지만 파티 버프·정보. 추천: hp 하·나머지 하, speed 상(먼저 버프 뿌리기). 핵심: 아군 광역 might/edge 부여, 적 약점 노출(weaken). 2층부터 합류.
- **문영철** (권투 선수·딜러) — 정타 타격형. 추천: accuracy 상·critChance 중·hp 중. 핵심: 연타 콤보(낮은 cooldown 단일 damage), 카운터 패시브. 2층 합류.
- **김무옥** (쌍칼패 행동대장·탱커) — 묵직한 전위. 추천: hp 상·evasion 하. 핵심: 도발(taunt) + shield 자생. 2층 합류.

## 맵 구성 (노드 흐름)

start → [1층] → clear → [2층] → boss(구마적) → [3층] → boss(왕발) → boss(다나까) → clear

### 1층 — 입문과 합류
- **N1 (event) — 사동옥 급습 / 원노인 순국:** 비전투 인카운터. 선택지: ①미와에 맞서 저항(전투 진입 + 민심+, hp 손실) ②굴복(hp 보존, 민심−). 결과로 **복수 맹세 버프**(미와 계열 적 상대 damage+) 획득. 원노인의 "장군의 아들" → 두한 환영 부활 패시브 해금.
- **N2 (event) — 만주행 좌절:** 도박형. 털보 여비 사기. 선택지: ①추궁(전투) ②포기(gold 손실). 추궁 성공 시 쌍칼 조직 접촉.
- **N3 (combat) — 두한 vs 김무옥·문영철:** 입문 전투. 적: 김무옥(탱커, 도발)·문영철(권투 딜러). 두한 단독. 의도=콤보/그래플 기본 습득. 클리어 후 두 명은 **패배→이후 합류 복선**.
- **N4 (event/classChange) — 쌍칼의 칼 투척 시험:** 쌍칼이 칼 세 자루를 던짐. **위협 판정**(fear 저항 체크) — 미동 없이 통과 시 쌍칼 조직 합류(파티 슬롯 +, 민심+). 합류 = 1차 전직 노드 성격(거리의 독립군 패시브 부여).
- **N5 (elite) — 신마찌 유곽 다대일 / 기따노("독사"):** 다대일 버티기. 적: 야쿠자 잡졸 3~4(군집)+엘리트 **기따노**(일본도, 무기 보너스). 두한 맨손 핸디캡 구도. 의도=무장 해제(제비식 단도 떨구기)·발차기 콤보 검증. 클리어 시 손기정 우승 겹침 → 민심 대폭+.
- **N6 (rest/shop) — 우미관 야시장:** 회복 + 상점(스킬·특성 구매). 1층 clear.

### 2층 — 승계와 증명
- **N7 (event) — 쌍칼 vs 구마적 결투(관전):** 비전투 서사 노드. 쌍칼이 칼 봉인한 채 박치기에 패배 → 두한을 후계 지목. 결과: **이정목 오야붕 승계**(김영태·김무옥·문영철 파티 합류, 진형 4×4 개방).
- **N8 (combat) — 이정목 사수 / 뭉치 다대일:** 적: 뭉치(군집 리더)+제비(단도)+잡졸. 1:다 군집 전투. 두한 발차기 광역으로 격파. 의도=신규 파티원 활용.
- **N9 (elite) — 두한 vs 신마적:** 엘리트 결투. 적: **신마적**(광폭 딜러, 목 조르기 그래플). 구조: 신마적의 그래플에 걸리면 **박치기 탈출 카운터**로 역전. 패배한 신마적 → "종로를 부탁한다" + 민심+ + 정보(구마적 약점) 획득.
- **N10 (event) — 혼마찌/하야시 저택 잠입:** 도박/잠입. 애란 구출. 선택지: ①신문지 뭉치 허세(심리전 판정, 성공 시 gold 강탈+애란 구출, 민심+) ②정면 돌파(전투). 하야시 첫 등장(회유 떡밥).
- **N11 (event) — 사쿠라 개업식 vs 종로회관 기습:** **분기**. 우미관패의 비겁한 집단 기습. 선택지: ①정면 응전(전투, hp 큰 손실) ②후퇴(hp 보존). 어느 쪽이든 "비겁한 뒤통수"로 **도덕적 명분이 두한에게 이전 → 다음 보스전 민심 보너스**. 만해 격려 → 환영 부활 강화.
- **N12 (rest) — 설향의 암자:** 부상 치료(대형 회복). 공개 도전장 발송.
- **N13 (BOSS) — 두한 vs 구마적 (패권 결투):** 보스 노드, 적 진형보너스 ON. 적: **구마적**(박치기·손도끼 탱커 보스)+호위 뭉치·왕발(1페이즈만). **2페이즈 구조:** 1페이즈 구마적 박치기에 두한 기절(HP 0) → **환영 부활 발동**(김좌진 환영, might 대폭+) → 2페이즈 발차기 KO. 민심 게이지가 높을수록 부활 후 버프 강화. clear=2층 종료, 우미관 입성.

### 3층 — 통일과 새 적
- **N14 (event/classChange) — 통합 연설 / 가족 화해:** 세금 절반·직업 보유·일본패 단절 규율 선포. **2차 전직 노드**(우미관 오야붕 전용 스킬 해금). 민심 최대치 상승.
- **N15 (combat) — 서대문 작두 복속:** 적: **작두**(지역 오야붕)+부하. 발차기 역전. 클리어 = **세력 복속 트리 첫 노드**("식구 되러 왔다" → 임시 아군 증원 해금).
- **N16 (combat) — 마포 용식 창고 다대다:** 다대다 전투. 적: 용식+마포패 다수. 복속한 작두 증원 활용. 심리전 요소.
- **N17 (event) — 시구문 짝코 심리전:** 비전투 굴복 노드. 민심·세력 규모 판정으로 무혈 복속(전투 회피) 또는 전투.
- **N18 (BOSS) — 왕발 (총기 보스/특수):** 보스. 적: **왕발**(규범 파괴자, 총기=고위력 즉사 위협). **특수 메커니즘:** 왕발의 사격은 단일 대상 초고damage(즉사급). **정진영 헌신 패시브**로 두한 대신 피격(서사 재현). **심리전 페이즈:** "쏴라" — 민심이 충분히 높으면 왕발 행동불가(fear·paralyze 자가 부여) → 추방. 민심 낮으면 정면 전투.
- **N19 (BOSS) — 다나까 (아사히마찌 아편 야쿠자):** 최종 보스. 적: **다나까**+아편 야쿠자단(poison/약물 디버프 살포). 와싱턴 구출 소굴 습격. 적 진형보너스 ON, 독 도트 압박. 클리어 = 런 종료, "남은 적은 일본 야쿠자" 다음 런 복선.

**미와(고등계) 페이즈:** 전 층에 걸친 비전투 **추격/감시 노드**로 산재(요시찰 강화). 일정 민심 이하로 떨어지면 미와 추격 강제 전투 발동 — 잡히면 hp/gold 페널티. 최종 숙적은 다음 런으로 이월.

## 적 캐릭터 (로스터)

- **김무옥** (쌍칼패→아군) — 탱커. 도발+자생 shield. AI: 전위 고정, 두한 보호. 패배 후 합류.
- **문영철** (권투→아군) — 정타 딜러. 카운터 패시브(damaged→반격). 패배 후 합류.
- **기따노 "독사"** (신마찌 야쿠자) — 일본도 무기 보너스 딜러. accuracy 상·critMultiplier 상. AI: 최전열 단일 집중. 무장 해제(move/단도 떨구기)에 취약.
- **신마적(엄동욱)** (학생패) — 광폭 딜러. 목 조르기 그래플(taunt+freeze 자가 콤보). 다대일 광역 압도. AI: 최약체 우선 그래플. 박치기 카운터에 약점.
- **뭉치** (우미관패) — 군집 리더. 잡졸 소환·버프. AI: 후열에서 증원·자버프.
- **제비** (우미관패) — 단도 암살자. 고critChance 단일. AI: 후열 침투, 무장 해제 시 무력.
- **구마적** (우미관 오야붕·보스) — 박치기·손도끼 탱커 보스. hp 최상·might 자생. **선제공격 개시**(battleStart→might). 박치기=그래플 카운터 고damage. 약점: 회복 불가 누적/2페이즈 환영 부활에 취약.
- **작두** (서대문 오야붕) — 지역 보스. 중탱커. 발차기 역전 구조. 패배 후 복속.
- **용식** (마포 오야붕) — 다대다 군집 보스. 패거리 다수 지휘.
- **짝코** (시구문 오야붕) — 심리전 굴복형. 직접 전투보다 협상.
- **왕발** (전 구마적 부하·보스) — 규범 파괴자. **총기=단일 즉사급 damage**(사용 시 적측 민심/아군 이탈 페널티 모티프). 만취 디버프. 심리전(fear)에 붕괴.
- **다나까** (아사히마찌·최종 보스) — 아편 야쿠자. poison/약물 디버프 살포 + 진형보너스. 소굴 다수 호위.
- **하야시** (혼마찌 오야붕·비전투) — 책략가/지원형. 직접 전투 대신 **회유·매수 외교 노드**의 주체(적 세력 아군화 시도). "사무라이 의리"로 비겁한 수 거부 → 일부 노드 명분 보너스 제공.
- **미와** (고등계 경부·추격형) — 비전투 감시/추격 노드 주체. 민심 저하 시 강제 전투.

## 설계할 스킬·패시브 (이 런 신규 콘텐츠 후보)

대부분 **기존 프리미티브 조합 = 데이터-온리**. 신규 필요분만 명시.

- **박치기 (그래플 탈출 카운터)** — 자신이 freeze/taunt(목 조르기) 상태일 때 발동, cleanse(자기 상태 해제) + 시전자에게 damage. `applyStatusSelf` 해제 + `damage`. when=damaged/turnStart + if=hasStatus(freeze) → then=cleanse+damage. **데이터-온리.**
- **발차기 콤보** — 낮은 cooldown 단일 damage, 연속 시 누적. 무장 해제 효과는 `move`(적 단도 떨구기 추상화)나 `applyStatus(weaken)`로. **데이터-온리.**
- **칼 투척 위협** — 비전투/전투 기선제압: `applyStatus(fear, stacks)` target=enemy, alwaysHit. 쌍칼 전용. **데이터-온리.**
- **고간 잡기 (개코 필살 그래플)** — 단일 고damage + `applyStatus(paralyze)`. critChance 보정. **데이터-온리.**
- **일본도/단도 무기 보너스** — 적 패시브: battleStart→`applyStatusSelf(might/edge)`. 맨손 핸디캡은 플레이어 스탯 설계로. **데이터-온리.**
- **환영 부활 (각성)** — HP 0 도달 시 1회 부활 + might 부여. when=death + if=확률/1회제한 + then=heal(부활)+applyStatusSelf(might). → **신규 프리미티브 필요 여부 확인:** undying 상태이상이 "치사 1회 무효"를 이미 커버하면 **데이터-온리**(undying + 부활 시 heal/might를 패시브 then으로). 다만 "민심 게이지 비례 부활 강도"는 아래 게이지가 프리미티브 갭.
- **헌신 방패 (정진영)** — 아군 대신 피격: `applyStatus(taunt)` self + `shield` ally. 반사 서사는 reflectByDamage 패시브. **데이터-온리.**
- **군집 소환 (개코 거지패)** — 임시 아군 토큰 동원. → **신규 프리미티브 필요:** 전투 중 임시 유닛 소환(summon)은 현 effect 목록(damage/status/shield/heal/cleanse/move)에 없음. **"summon 이펙트(임시 캐릭터 생성, N턴/전투 한정)"가 프리미티브 갭** — 엔진 변경 필요. 대안(데이터-온리): 소환 대신 자버프(might/edge)나 진형 동료 사전 배치로 추상화 가능. 소환을 원작 충실하게 하려면 보고·승인 필요.
- **민심·명분 게이지** — 약자 보호·세금 감면으로 충전, 기습 피격·총기 대응으로 감소. 세력 복속 확률·증원·환영 부활 강도·심리전(왕발/짝코) 판정에 영향. → **신규 프리미티브 필요:** 전투 외부에 존재하는 **런 레벨 영속 자원(run-scoped resource)** + 노드 해소·전투 시작값에 영향을 주는 훅은 현 노드/RunState 모델에 명시적 자원 개념이 없음. **"런 자원 게이지(민심) + 노드/전투 모디파이어 훅"이 프리미티브 갭** — 엔진 변경 필요. 데이터-온리 대안: event 노드 선택지의 분기 플래그(이미 가능한 런 상태 플래그)로 근사 가능하나, 연속 게이지·전투 모디파이어 연동은 불가.

## 전직·특수 메커니즘 (해당 시)

- **두한 전직 트리(4.7):**
  - 0차(무소속): 맨손 콤보 기본.
  - 1차(쌍칼 조직 합류, N4): "거리의 독립군" 패시브 — 민심 보유 시 damage+, 약자 보호 트리거 활성. 전용 스킬 보상: 칼 투척 위협류 견제.
  - 2차(이정목 오야붕, N7): 참모 연계 패시브 — 김영태 버프 수혜+. 진형 4×4 개방·열보너스.
  - 3차(우미관 오야붕, N14): 패권 패시브 — 환영 부활 강화 + 세력 복속 트리 해금. 전용 스킬: 통합 광역 마무리기.
  - **분기는 패시브로 차별**: 민심 특화(저항형) vs 무력 특화(결투형) 갈래를 같은 직업 트리 내 패시브 선택으로.
- **세력 복속 트리(3층):** 작두→마포 용식→시구문 짝코 정복 체인. 복속한 오야붕 = 임시 증원/진형 보너스. (증원 = 위 군집 소환 프리미티브 갭과 연동 — 미승인 시 진형 사전 배치로 대체.)
- **다대일 버티기 챌린지:** 신마찌(N5)·마포 창고(N16) — 단신/소수로 군집 생존. 별도 메커니즘 없이 적 수·배치로 구현(데이터-온리).
- **심리전 페이즈:** 왕발(N18)·짝코(N17) — 민심 게이지 판정으로 무혈 굴복(fear/paralyze 강제) 또는 전투. 게이지 미승인 시 event 선택지+확률로 근사.

## 난이도·길이·보상 흐름

- **길이:** 3층 ~19 노드 + 미와 추격 산재. 1런 클리어 목표. 전투/엘리트/보스 비율 대략 combat 6 : elite 2 : boss 3 : event 5 : rest·shop 3.
- **난이도 곡선:** 1층=입문(두한 단독·소수, 콤보 학습) → 2층=중(파티 확장·일기토 보스 구마적, 2페이즈 부활 손맛 정점) → 3층=상(다대다·총기 즉사 위협·독 압박·외교 변수).
- **보상 흐름:**
  - 전직 노드(N4·N7·N14)에서 파티 슬롯·진형·전용 스킬 단계적 해금.
  - 패배 적의 합류(김무옥·문영철)·복속 오야붕(작두 등) = 전력 증강 보상.
  - 민심 게이지(승인 시) = 메타 보상축: 약자 보호·세금 감면 선택 → 보스전 부활 강화·무혈 복속 → 효율 클리어. 기습·총기 대응 → 민심 손실 → 미와 추격 리스크.
  - shop/rest는 층 사이 1회씩, 결투 전 회복 보장(N12 암자).
- **시그니처 손맛:** 구마적전 환영 부활 역전(2층 클라이맥스)과 왕발전 "쏴라" 심리전 압도(3층 클라이맥스)가 이 런의 두 정점. 맨손으로 무기·총을 이기는 카타르시스가 전 런의 일관 테마.

**프리미티브 갭 요약(구현 전 승인 필요 3건):** ① **summon**(전투 중 임시 아군 — 개코 거지패/세력 증원) ② **런 자원 게이지(민심) + 노드/전투 모디파이어 훅** ③ **환영 부활의 게이지-비례 강도**(②에 종속). 나머지 모든 스킬·패시브·결투 구조는 **데이터-온리**로 구현 가능. 셋 다 데이터-온리 대안(자버프·진형 사전 배치·event 플래그·확률)으로 근사 가능하나, 원작 충실도를 위해서는 엔진 프리미티브 추가 권장 — `types/content.ts` + `engine/spr-core`(summon=전투 모듈, 민심=RunState 자원·노드 해소 훅) 변경.
