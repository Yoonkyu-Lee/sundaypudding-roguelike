# 런 5: 사형·전쟁기 (미군정~6.25) (원작 77~89화)

## 컨셉 (이 아크 → 런)

야인시대 전체의 분수령. **사형수 김두한이 전쟁 영웅으로 부활**하는 개인 서사와, **동대문 상인연합회(이정재)가 태동**하는 권력 서사가 평행하게 교차하는 장대한 아크다. 한 런으로서는 "정의의 좌절 → 전란의 혼돈 → 두 거물의 갈림"을 3개 층(layer)으로 압축한다.

- **층 1 — 사형·청산 (77~80화):** 닫힌 결투(오키나와 킥복싱)와 반민특위 추격·붕괴. 1:1 페이즈 보스와 "패배 확정형" 이벤트가 공존하는 무거운 도입. 플레이어는 김두한 단신 또는 소수로 시작 → 별동대 합류.
- **층 2 — 전란·생존 (81~85화):** 6.25 발발, 한강 도하, 점령 서울 탈출, 부두 파업, 학도병 영천 전투. 웨이브 전투와 **협상/회피 분기**가 늘어나고, "권총=주먹 룰 파괴" 변수가 처음 등장.
- **층 3 — 조직·갈림 (86~89화):** 문영철 전사, 부산 유흥가 청소, 동대문 연합회 출범. 전직(classChange) 분기 — 김두한=노동·참전 노선, 이정재=조직 보스 노선이 패시브로 갈린다. 보스=연합회 상견례(적 진형보너스 ON, "배신=죽음" 규율).

플레이 경험: 전반은 **역전형 1:1 카타르시스**(저HP 강화 김두한), 중반은 **약체 아군을 지휘 버프로 끌어올리는 분대전**, 후반은 **권총 글래스캐논 vs 주먹 탱커**의 양식 충돌과 조직 충성 메커니즘. 한 런에 "통쾌함(서양 챔피언·미군·계엄사령관 격파)"과 "비극(전사·납치·처형)"이 교차한다.

## 플레이어 파티 (등장 캐릭터)

- **김두한 (별동대장)** — 런 5의 축. 박치기+공중발차기 혼합 근접 딜러. **역전형 패시브(저HP일수록 공격↑)**가 핵심 모티프. 추천: hp 높음·accuracy 중·critChance 높음·critMultiplier 160~180. 핵심 스킬: 박치기(스턴 일격)·공중발차기(처형 마무리)·지휘(아군 might 부여). 패시브: 「불굴 투혼」(hpPct<40% → applyStatusSelf might).
- **문영철 (학도병 교관)** — 우미관 식구. 방어·보조형 근접. 추천: hp 중·evasion 중·accuracy 높음. 학도병 인솔 모티프 → 아군 shield 부여. **층 3에서 전사 이벤트로 이탈**(서사적 상실, 잔존 파티 강화 보상).
- **이화룡 (명동패 오야붕)** — 동맹. 한강 도하·부두 공동 참여. 균형형 근접 딜러+이동 유틸(move). 추천: speedMax 높음(선공)·evasion 높음.
- **시라소니 (명동 주먹 고수)** — 유격/침투 특화. 높은 evasion·critChance, 단일 강타. **층 3에서 켈로부대 전직 분기**(잠입 패시브 해금). 추천: speedMin/Max 높음·critMultiplier 높음.
- **이정재 (특경대→조직 보스)** — 듀얼 노선 캐릭터. 초반=청산 이상주의 근접, 후반=**부하 지휘·권총 사격 겸비**. classChange로 「동대문 회장」 전직 시 도발+소환 보조 패시브. 추천: hp 높음·accuracy 중. 핵심: 「배신=죽음」 규율(아군 taunt 자기지정으로 적 시선 흡수, 처형 콤보).
- **홍만길·김관철·아구·갈치 (우미관패, 묶음 영입)** — 저스탯 분대원. 단독으론 약하나 김두한 「지휘」 버프로 가치 상승. 학도병 웨이브에서 머릿수 역할. 추천: 저hp·중accuracy. 데이터-온리(기존 스탯 조합).

## 맵 구성 (노드 흐름)

3개 층, 각 층 시작=헥스 인접 무방향그래프. clear 노드(층 보스/이벤트) 도달 시 층 종료.

### 층 1 — 사형·청산
- **start → event「미 군법회의·자해」(77화)** — 선택지/도박 노드. 김두한 vs 미 군정(아놀드·하지). "한국 법정에서 죽겠다"는 자해 선택 = applyStatusSelf로 즉시 hp 손실 but might/edge 영구 부여(도박). 거부 시 무난 통과·보상 적음. 패배 불가(서사 고정).
- **boss「오키나와 킥복싱: 김두한 vs 마이클 상사」(78화)** — **1:1 페이즈 보스**. 적 진형보너스 ON. 페이즈1: 마이클이 정통 복싱으로 압도(김두한 hp 강제 저하 구간 → 역전 패시브 발동 설계 의도). 페이즈2: 박치기로 스턴 → 공중발차기 KO. 의도: 역전형 패시브의 첫 쇼케이스.
- **event「특별사면·노동운동 입문」(79화)** — 데코/이벤트. 이승만 돈봉투 거절(gold 포기 → 평판/패시브 보상) vs 수령(gold↑·관계 냉각 플래그) 분기. 전진한 노총 제안=문영철·우미관패 영입 트리거.
- **elite「반민특위 vs 노덕술·친일 경찰」(79~80화)** — 강화 전투. 이정재·특경대 합류 전투. 적: 노덕술(흑막·은신)+친일 경찰 다수. 추격·체포 의도, 적 도주 메커니즘.
- **clear: event「6.6 사태」(80화)** — **패배 확정형 이벤트 노드.** 반민특위 강제 해산(서사상 승리 불가). 이정재 고문 후 석방→포목장사 플래그. 곽영주 "하옵니다" 발탁(층 3 적 버프 복선). 보상=다음 층 강화 아이템(굴욕→재기).

### 층 2 — 전란·생존
- **start → event「6.25 발발·정보 은폐」(81화)** — 텍스트/선택지. 일상 vs 피난 판단(준비도 도박). 잘못된 선택 시 다음 전투 디버프.
- **combat「한강 인도교·나룻배 도하」(82화)** — 일반 전투+이동 퍼즐. 명동패 동맹 호위 하 도하. move(deltaCol) 재배치 강조. 적: 통제 경찰·혼란 군중(약).
- **event「점령 서울 잠입·구출」(83화)** — **스텔스/탈출 노드.** 명월관 습격(애기보살 납북=서사 손실), 김기홍 위장 잠입으로 이정재 구출. 잠입 성공=은신 보너스, 실패=추격전 전투.
- **elite「부두 파업: 우미관·명동 연합 vs 고사이마찌패」(84화)** — 패싸움 엘리트. **적의 권총 변수 첫 등장**(고사이마찌 → 황병관 사살 이벤트). 황병관(아군 그래플러)이 총격으로 이탈하는 서사. 미군 중재 협상으로 임금 4배 보상.
- **branch event「김두한 vs 김종원」(84화)** — **협상/회피 분기 노드.** 총 대치 → 협상(전투 회피·gold/임금 이득) vs 강공(전투·리스크). 협상 능력 보유 시 우대.
- **clear: boss「학도병 영천 고지전」(85화)** — **야간 돌격 웨이브 전투.** 학도병+우미관패 vs 인민군. 다파(wave) 적. 김두한 「지휘」로 약체 학도병 강화가 클리어 핵심. 전투 중 문영철 중상 → 층 3 전사 복선.

### 층 3 — 조직·갈림
- **start → event「문영철 전사」(86화)** — 서사 이벤트. 문영철 영구 이탈, 잔존 파티 might/edge 영구 부여(상실→분노 보상).
- **combat「부산 카바레 급습·유흥가 청소」(86~87화)** — 일반 전투. 후방 향락 고위층 응징. 방화 모티프(burn 광역).
- **classChange「전직 분기」(86~89화)** — **인원 캡 전직 노드.** 김두한=「노총/참전」(지휘·역전 강화) vs 시라소니=「켈로부대」(잠입·유격) vs 이정재=「동대문 회장」(소환·도발·권총). 차수별 전용 스킬 보상 해금.
- **branch event「국민방위군 사령관 제안 거절」(87화)** — 이승만 원스타 제안 거절(관계 냉각·독립 패시브) vs 수락(권력 버프·서사 분기). 김두한 노선 강화.
- **elite「이정재 vs 도끼패」(85화)** — **2연속 미니 보스.** 격퇴 후 시라소니 의형제 영입 분기. 이정재 노선 강화.
- **clear: boss「동대문 상인연합회 창립 상견례」(87~88화)** — **최종 보스(적 진형보너스 ON).** 이정재(회장)+임화수+이석재(권총 명사수)+이억일(당수 탱커)+곽영주(경무대 버프 서포터). "의리=목숨, 배신=죽음" 규율 = 적 충성 콤보. 권총(이석재)·탱커(이억일)·버프(곽영주) 복합 진형. 클리어=런 5 종료, 휴전(89화) 에필로그.

## 적 캐릭터 (로스터)

- **마이클 상사** — 미군 챔피언. 정통 복싱 보스. 페이즈1 거의 무적(높은 evasion+shield 자동), 페이즈2 약점 노출(스턴 피격 시 방어 붕괴). AI: 페이즈1 공격적 연타, 페이즈2 패닉 방어. 패시브: 「챔피언의 가드」(battleStart → 대량 shield, 박치기/스턴 피격 시 cleanse 당함=약점).
- **노덕술** — 친일 수사부장. 흑막 보스. 직접 싸우지 않고 부하 뒤 은신(낮은 노출), 고문/암살 의뢰=디버프 살포. 패시브: 「은신」(hpPct<50% → 도주/타겟불가 임시), 「암살 의뢰」(turnStart → 무작위 아군 weaken). AI: 회피·생존 우선.
- **친일 경찰 (다수)** — 노덕술 부하. 평범한 근접·곤봉. 머릿수 압박. 6.6 사태에서 반민특위를 수적으로 제압.
- **고사이마찌** — 부두 터줏대감. **권총 글래스캐논**. 낮은 hp, 높은 accuracy 원거리 즉사형 사격(주먹 룰 파괴). 패시브: 「권총의 시대」(onHit → 확률 즉사/대량 damage, 단 근접 피격 시 취약). AI: 후열 고정, 고가치 타겟(그래플러) 저격.
- **인민군 (웨이브)** — 영천 전투 적. T-34 모티프 정예+징집병 다수. 야간 돌격에 약함(첫 턴 기습 보너스 구간). 일부 총칼 보유=학도병 처형 위협(문영철 중상 트리거).
- **도끼패** — 부산 피난기 약탈 무리. 2연속 미니 보스, 거친 광역 근접. 격퇴 후 일부 영입 가능.
- **이정재 (최종 보스)** — 조직 회장. **부하 소환·도발·권총 겸비.** 패시브: 「배신=죽음」(아군 death/배신 시 → 잔존 아군 might 대량, 적 fear). AI: 진형 유지·서포터 보호. 의리 콤보의 축.
- **임화수** — 연합회 2인자. 자금·정보형 버프 서포터. CIC 문관증 모티프=아군 「관통(pierce)」 부여(권력으로 방어 무시).
- **이석재** — 권총 명사수(8발 전탄 명중). 원거리 정밀 딜러. accuracy 극高·alwaysHit급. 후열 고정.
- **이억일** — 당수 7단. 경호 탱커. 높은 hp·도발·shield. 회장 보호.
- **곽영주** — 경무대 배경 서포터. 직접 전투 약함, **소환/배경 버프 제공**(turnStart → 무작위 적군 강화). 패시브: 「경무대 전화」(battleStart → 아군 전체 accuracy↑).

## 설계할 스킬·패시브 (이 런 신규 콘텐츠 후보)

원작 싸움 방식 → 프리미티브 매핑. (대부분 기존 프리미티브 조합 = **데이터-온리**)

- **박치기 (헤드버트)** — damage(고) + applyStatus(freeze 또는 paralyze, 1턴) + grantsInterrupt. reach=근접. 반칙성 스턴 일격, 페이즈 전환 트리거. [데이터-온리]
- **공중 발차기** — damage(극고, 처형 마무리) + accuracy 보너스 if 대상 hasStatus(freeze). cooldown 김. 스턴 후 콤보. [데이터-온리]
- **지휘/사기 진작 (김두한)** — applyStatus(might,) target=ally area=all/row. 약체 학도병 강화. [데이터-온리]
- **불굴 투혼 (역전 패시브)** — when=damaged + if=hpPct<40% → then=applyStatusSelf(might,edge). 저HP 강화. [데이터-온리]
- **레슬링 메치기/허리 꺾기 (황병관)** — damage + applyStatus(paralyze) area=row/col. 광역 제압. [데이터-온리]
- **권총 사격 (이석재·고사이마찌·노덕술)** — damage(고) + alwaysHit 또는 accuracy 극高 + pierce(방어 무시). area=single, reach=원거리(reach 무관/free 타겟). "주먹 룰 파괴" 변수. [데이터-온리] — 단 **즉사(현재 hp 무시 처치)**가 필요하면 → 아래 신규.
- **위장 잠입 (김기홍)** — move + applyStatusSelf(invincible/은신 1턴) + cleanse(아군). 적 진영 진입·구출 유틸. [데이터-온리]
- **챔피언의 가드 (마이클)** — when=battleStart → shield(대량); when=damaged + if=hasStatus(freeze) → cleanse(자기 shield 제거)=약점. [데이터-온리]
- **암살 의뢰 (노덕술)** — when=turnStart → applyStatus(weaken) target=무작위 적(=플레이어). [데이터-온리]
- **배신=죽음 (이정재)** — when=death(아군 사망) → then=applyStatus(might) 잔존 아군 + applyStatus(fear) 적 전체. 조직 충성 콤보. [데이터-온리]
- **협상/대치 (김두한-김종원)** — 전투 회피·이득 교환. **전투 스킬이 아니라 event 노드 선택지**로 구현(런 노드 해소 프리미티브). [데이터-온리 / 노드]

### 신규 프리미티브 필요 (보고·승인 대상)

원작 충실을 위해 다음 두 가지는 기존 프리미티브로 원자적 표현이 **불가**할 수 있어 명시한다:

1. **즉사(execute) 효과** — 「권총 사격」의 "전탄 명중·즉사" 낭만(이석재 8발, 고사이마찌 황병관 사살)을 진짜 즉사로 표현하려면. 기존 damage(amount)로는 "현재 hp 무시 처치"가 원자적으로 불가(고정 대량 damage로 근사 가능하나 탱커엔 부족). → **신규 SkillEffect `execute(hpPctThreshold)`**(임계 이하 대상 즉시 처치) 또는 `damage`에 `lethalIfBelow` 필드. **데이터-온리 아님 — 엔진 프리미티브 추가.** 추가 위치: `types/content.ts` SkillEffect + `core/<skill resolve>`. (대안: 고정 대량 damage로 근사 = 데이터-온리. 권총의 즉사 카타르시스를 살릴지 사용자 판단 필요.)

2. **페이즈 전환 보스(phase)** — 마이클전·이정재 최종전의 "특정 트리거 시 거동 전환"(가드→붕괴, 부하 전멸→격노). 기존 when=damaged/hpPct 패시브 + applyStatusSelf 조합으로 **거동 변화는 근사 가능**(저HP 시 강화/약화). 단 "스킬 풀 자체 교체·AI 프로필 전환"이 필요하면 → **신규: 적 캐릭터 phase 정의(hpPct 임계 시 skillIds/aiProfileId 스왑)**. 우선은 패시브 근사로 [데이터-온리] 구현 권장, 부족 시 승인 후 phase 추가.

그 외 자해(applyStatusSelf+self damage)·은신(invincible/taunt 해제)·소환은 기존 프리미티브 조합으로 충분(데이터-온리).

## 전직·특수 메커니즘

- **classChange 노드 (층 3):** 인원 캡 내 핵심 3인 전직 분기 — 패시브로 노선 차별화.
  - **김두한 → 「노총·참전」:** 지휘(아군 광역 might) 강화 + 역전 패시브 2차(hpPct<25% → edge 추가). 전용 스킬: 학도병 돌격(아군 전체 shield+선공).
  - **시라소니 → 「켈로부대」:** 잠입 패시브(battleStart → 1턴 은신/선제) + 단일 처형 강타. 유격 노선.
  - **이정재 → 「동대문 회장」:** 「배신=죽음」 강화 + 부하 소환(turnStart 일정 확률 아군 호출 근사=applyStatusSelf taunt로 시선 흡수) + 권총 사격 해금.
- **조직 충성도 (이정재 노선):** "배신=죽음" = 아군 사망/이탈을 트리거로 잔존 파티 폭주 버프 + 적 fear. 배신(특정 이벤트 선택) 시 즉결 페널티(아군 hp/스탯 손실). 데이터-온리(특성 when=death + 노드 선택지).
- **권총=양식 전환 (서사 장치):** 층 2부터 적 진영에 권총 유닛 등장 → "주먹 룰"이 깨지는 난이도·테마 전환. 글래스캐논(저hp·고화력 원거리) = 근접으로 빨리 처치해야 하는 우선 타겟. 데이터-온리(스탯/배치).
- **패배 확정 이벤트 (6.6 사태·염동진 총살):** 승리 불가, 서사 고정. 굴욕·상실 → 다음 층 보상으로 재기. 런 노드 해소 프리미티브로 구현(text/grantStatus 데코 + 강제 진행).

## 난이도·길이·보상 흐름

- **길이:** 3개 층, 층당 5~7노드 (총 ~18노드). 야인시대 최장 아크답게 런 5는 캠페인 중반 분량 = 캠페인 최대 길이 런 중 하나.
- **난이도 곡선:**
  - 층 1 = **중**(1:1 페이즈 보스로 메커니즘 학습, 역전 패시브 튜토리얼). 패배 확정 이벤트로 정서적 무게.
  - 층 2 = **중상**(웨이브+권총 변수+협상 분기. 머릿수/지휘 운용 시험). 그래플러 이탈(황병관)로 자원 압박.
  - 층 3 = **상**(최종 보스=복합 진형 보너스 ON. 권총 명사수+탱커+버프 서포터 동시. 충성 콤보 대응 필요).
- **보스 수치 방향:**
  - 마이클: hp 2.0~2.5×기준, 페이즈1 evasion 높음+자동 shield, 페이즈2 방어 붕괴. 역전 유도형.
  - 영천 인민군 웨이브: 개체는 약(0.6×) but 다수 3~4웨이브, 첫 턴 기습 보너스로 속전 유도.
  - 이정재 최종 진형: 회장 hp 2.5×+탱커(이억일) 도발, 명사수(이석재) 후열 즉사 위협, 곽영주 버프. 권총 우선 처치 → 도발 돌파 → 회장 순. 진형보너스로 열0 보호.
- **보상 흐름:**
  - 돈봉투 거절/수령, 협상/강공, 사령관 거절/수락 = **gold vs 패시브·관계 플래그** 트레이드오프(서사 선택이 빌드에 직결).
  - 층 클리어 보상: 층1=재기 아이템(굴욕 보전), 층2=임금 4배(gold 대량)+학도병 머릿수, 층3=전직 전용 스킬.
  - 영입: 우미관패(머릿수)·이화룡/시라소니(동맹)·도끼패 잔당(격퇴 후). 상실: 황병관(부두)·문영철(영천→전사)·애기보살(납북, 서사)로 균형.
- **테마 보상 설계:** 통쾌함(서양 챔피언·미군·계엄사령관 격파=대량 보상)과 비극(전사·납치·처형=강제 손실 but 분노 버프)을 교차해, "정의의 좌절→재기→갈림"의 정서 곡선을 보상으로 체감하게 한다.
