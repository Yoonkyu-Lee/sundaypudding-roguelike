# 런 1: 유년·성장 (원작 1~8화)

## 컨셉 (이 아크 → 런)
**"맨주먹 고아 소년이 밑바닥에서 사나이로 빚어지는 성장 런."** 시작은 가진 것 없는 소년두한 단 한 명 — 파티가 아니라 **단신 생존**으로 출발한다. 런을 진행하며 동료(개코·정진영)를 합류시키고, 후견인 원노인의 거점에서 보급받고, 스승 유태권에게 무술 프리미티브(필살기)를 전수받아 **약한 캐릭터가 강해지는 곡선** 자체가 플레이 경험이다. 정체성 상징인 **회중시계**는 런 내내 지키는 아이템(잃으면 페널티) — 원작 "끝까지 사수"를 메타 긴장으로.

3개 층 구조:
- **1층 — 개성 (착취·탈출):** 잠입/이벤트 위주. 적은 약하고 자원(시계 탈환·빚 장부)이 보상. 튜토리얼 난이도.
- **2층 — 경성 거지촌 (생존·패권):** 추격·다수전. 동료 합류, 거지패 협동 메커니즘. 보스=왕초(1:1).
- **3층 — 사동옥 (수련·각성):** classChange(전직=무술 입문) + 훈련 노드로 필살기 해금. 엘리트=일본 학생 4인, 최종 정서 노드=부친 사망. 보스 없이 **성장의 완결**로 닫는다(다음 런 "종로 패권"으로 이월).

## 플레이어 파티 (등장 캐릭터)
- **소년두한 (kim_young)** — 런의 주축, 단신 시작. 컨셉=맨주먹·발차기 깡다구 브루저. 전투 스타일=최전열(열0) 근접, 쓰러져도 일어나는 불굴. 추천 스탯=HP 높음(40~46), evasion 중(8), critChance 높음(25, 발차기 역전), speedMin/Max 중(4~7). 핵심 모티프=**불굴(피격 후 1회 재기)**, **발차기 카운터(빈틈 고배율)**, 후반 **단전 차징 → 일격 필살**. 성장형 — 런 진행으로 스탯·스킬 해금.
- **개코 (gaekko)** — 2층 합류 동료. 컨셉=전라도 익살 정찰꾼, 비전투 지원형. 전투 스타일=후열(열3) 디버퍼/교란. 추천 스탯=HP 낮음(22), evasion 높음(13), 공격 약함. 모티프=**오물 방해(적 명중↓·약화)**, **장타령 기만(어그로 분산=도발 부여)**.
- **정진영 (jin)** — 2층 합류 동료. 컨셉=장님 어머니를 둔 독학파, 침착한 보조 딜러. 전투 스타일=중열, 단검·잡일. 추천 스탯=HP 중(28), accuracy 안정, critChance 중. 모티프=**침착한 일격(명중 보정)**, **응급 보조(약한 heal)**. (주의: 원작의 좌익 '정진영'과 동명이인 소년 캐릭터 — 별도 id `jin`.)
- (조력 NPC, 비전투) **원노인** — 거점 사동옥 운영자. rest/shop 노드의 화자(보급·정보). 전투 미참여. **유태권** — 3층 한시적 동료 겸 전직 스승(아래 전직 섹션).

## 맵 구성 (노드 흐름)

### 1층 — 개성 (착취·탈출)
- **start (event) — 만주 부자 상면:** 비전투 도입. 김좌진과 단 하루 상면, **회중시계 획득**(런 키 아이템·deco grantStatus 슬롯) + 선택지(시계를 "지킨다"=방어 버프 / "정신을 새긴다"=might 시작). 외조모 사망 텍스트로 톤 셋.
- **n1 (event) — 개성 외삼촌 착취:** 머슴살이 분기. 선택: ①굴종(gold 소량·HP 유지) ②반항(소규모 combat: 외삼촌패 thug×2, 보상 큼). 도박성.
- **n2 (event/잠입) — 가네야마 저택 방화:** **잠입 이벤트 노드**. "훔친 것과 빼앗은 것은 다르다" 분기 — ①협박 성공(시계 탈환 + 빚 장부 소각, 무전투 보상) ②발각(combat: 가네야마 + 하인 thug×2). 잠입 성공 시 회피 스탯/스킬 보상.
- **n3 (combat) — 추격 이탈:** 가네야마 추격대. 잡몹전(thug×3). 클리어 후 나석주·유태권과 조우(텍스트) → 경성행.
- **clear1:** 1층 종료.

### 2층 — 경성 거지촌 (생존·패권)
- **n4 (event) — 경성역 추격 (오물 방어):** **추격/회피 미니 노드.** 미와·오무라 추격을 거지 아이들이 오물로 막음 → 개코·정진영 **동료 합류**. 비전투, 협동 연출.
- **n5 (combat) — 거지촌 텃세:** 왕초 부하 거지패(beggar_thug×3). 동료 합류 첫 실전, 협동 디버프 튜토리얼.
- **n6 (shop) — 사동옥 보급(원노인):** 상점. 시계 관련 아이템·회복·범용 스킬 구매. 비전투.
- **n7 (rest) — 종로 적응(장타령):** 회복 노드. 개코의 각설이로 파티 heal + 소량 버프.
- **n8 (elite) — 미와 추격대 본대:** 강화 전투. 오무라+형사 다수(detective×2 + thug×2), 명중·고문(상태이상) 압박. 분기 합류점.
- **boss1 (boss) — 왕초 (거지촌 패권 1:1):** **챕터 보스.** 진형보너스 ON. 흙탕물 격투 — 두한이 동료 지원받아 왕초+거지패 호위를 격파. 발차기 역전 피니시가 게임적 클라이맥스.
- **clear2:** 거지패 대장 등극, 삼청동 거처 — 가족 재회 텍스트.

### 3층 — 사동옥 (수련·각성)
- **n9 (classChange) — 유태권 입문:** **전직 노드.** 두한이 유태권의 제자가 됨 → 무도가 전직(패시브 부여 + 1차 전용스킬 해금). 인원 캡 내.
- **n10 (event/훈련) — 새벽 수련:** **훈련/스킬해금 노드.** 삼각산 달리기·철봉·역도 = 영구 스탯 상승 선택(HP / SPD / crit 중 택1). deco grantStatus(영구).
- **n11 (elite) — 일본 학생 4인:** **엘리트(1 대 다수) 노드.** 조선 학생 구타하던 일본 학생 jp_student×4. 다수 제압 광역기 시험장.
- **n12 (event) — 나석주 의거 (목격):** **이벤트성 비극 노드.** 플레이어 비교전, 나석주 NPC가 일경 다수와 단독 총격전 끝에 순국하는 연출 + 정체 공개(미와=원수). 보상=결의 버스트(영구 might 또는 복수 패시브 해금).
- **n13 (event/훈련) — 통나무·샌드백 파괴:** 필살기 검증 노드. 단전·기 집중 **궁극기 해금**(통나무 파괴) + 날라차기 습득(샌드백 파열).
- **end (event) — 부친 사망·복수 맹세:** 보스 없는 **정서 피날레.** 김좌진 급사 전보, 미와의 사동옥 난입(원노인 위협 텍스트), "네 아비보다 더 큰 사람이 돼라" → 복수 맹세. 다음 런(종로 패권)으로 이월되는 메타 보너스 확정.
- **clear3 → 런 종료.**

## 적 캐릭터 (로스터)
- **왕초 (wangcho)** — 거지촌 전 두목/1층 보스. 군림형 폭력배, 환경물 활용. HP 높음(50~56), reach 근접, **돌 던지기(원거리 damage)**·**나뭇가지 후려치기(damage+bleed)**·**군림(자기 might + 거지패 도발)**. AI=guardian/bruiser(전열 압박). 호위로 beggar_thug 동반.

- **오무라/형사 (detective)** — 미와 부하. HP 중(24~30), 안정 명중, **수갑(paralyze)**·**곤봉(damage)**. AI=guardian/aggro.
- **가네야마 (kaneyama)** — 개성 악덕 지주. 비전투 우선(잠입으로 회피 가능), 발각 시만 전투. HP 중(26), **하인 호출**·**탐욕(자기 shield)**. AI=coward(자기보호).
- **일본 학생 (jp_student)** — 엘리트 다수전. HP 낮음(16), 떼로 몰림, **집단 구타(인접 시 damage↑ 패시브)**. AI=swarm. 4인 동시.
- **나석주 (naseokju)** — NPC 영웅(플레이어 조작 아님, 목격 연출). 권총+수류탄 원거리 폭발형, 자기희생. 데이터상 후속 런에서 한시 동료화 여지 — 이 런은 비전투 스크립트.

### 신규 프리미티브 필요 (명시)
1. **`blind` 상태이상 (명중률 직접 감소)** — 오물 방해의 정확한 표현. 현재 weaken(피해-)으로 근사 가능하나, "오물로 눈 가림=빗맞음"의 충실 구현엔 명중% 감소 상태가 필요. *대안: weaken로 1차 출시 후 갭으로 승격.* **[엔진 프리미티브 추가 후보 — 미승인]**
2. **잠입/스텔스 노드 결과(전투 회피 분기)** — 가네야마 방화·유태권 지붕 탈출. 현재 event 노드의 선택지+combat 분기로 **데이터-온리 표현 가능**(전투 노드를 조건부로 스킵). 별도 stealth 노드 타입은 불필요 → **[데이터-온리]**.
3. **시계=키 아이템(분실 페널티)** — items + deco grantStatus로 표현 가능하면 데이터-온리. "분실 시 상태 변화"가 노드 결과로 충분하면 갭 아님. **[데이터-온리 우선 검토]**

## 전직·특수 메커니즘
- **전직 (4.7): 무도가 입문 (n9 classChange).** 두한 직업 트리 1차 분기. 유태권 제자 입문 = 패시브 `qi_focus`(궁극 차징 강화: when:turnStart then:edge 소량 축적) 부여 + **1차 전용스킬 보상 해금**(`young_dash_kick`, 이어 n13에서 `young_dantian` 궁극). 인원 캡 내 단일 전직 — 후속 런에서 2차 전직(협객/주먹왕)으로 분기.
- **거지패 협동 (2층 데이터-온리):** 개코의 taunt 분산 + 정진영 보조 + 두한 전열 딜이라는 **3역 시너지**. 동료 합류 노드 보상으로 구성.
- **회중시계 메타 (런 통합 모티프):** start에서 획득 → 1·2층 위협(가네야마·왕초)에서 "사수" 분기. 끝까지 보유 시 end에서 추가 메타 보너스. 키 아이템 보유/분실을 노드 결과로 추적.
- **나석주 의거 = 비전투 정서 노드:** 플레이어 조작 없는 스크립트 전투(목격) + 정체 공개 + 영구 결의 버프. 전투 프리미티브 미사용.

## 난이도·길이·보상 흐름
- **길이:** 3층 ~13 노드 + start/end. 1회 30~45분. 첫 런=온보딩(단신→파티→전직 곡선이 곧 튜토리얼).
- **난이도 곡선:** 1층 매우 쉬움(단신이라 잡몹만, 잠입으로 전투 회피 가능) → 2층 상승(동료 합류로 파티 전투 본격화, 보스 왕초가 첫 진형보너스 벽) → 3층은 전투보다 **성장·정서 비중**(엘리트 1회 + 궁극 해금 + 피날레). 보스 부재로 "성장의 완결"로 닫아 다음 런에 텐션 이월.
- **보상 흐름:** 1층=시계 탈환·gold·회피 스탯 / 2층=동료 2명·범용스킬·거점 보급 / 3층=전직 패시브·영구 스탯(훈련)·궁극기 2종·결의 버프. **HP·스킬·전직이 단계별로 풀려** 약캐가 강캐 되는 체감을 보장.
- **수치 방향(요약):** 소년두한 HP 40~46(불굴 탱키), crit 25/×1.6(발차기 역전). 동료 HP 22~28(약체·지원). 왕초 HP 50~56(첫 벽). 잡몹 HP 14~18. damage 대역=시작기 8~10, 쿨기 12~14, 궁극 18~20 — 기존 콘텐츠(kim_*)와 동일 밸런스 대역 유지.
